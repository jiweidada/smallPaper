# 352 C 载体：横向分辨率关联零训练预检

冻结时间：2026-10-25T15:55:22.874Z。冻结时未查看 baseline/C 的逐 GT 匹配与分层收益。

目标：使用正式同配方 full96 的 seed0 EMA 权重，重新在本机 CPU、val548 上各推理一次，复现历史独立评估，再检验 C 的增益是否与目标宽度相关。通过后按用户明确授权启动训练；不再请求重复授权。

一、固定输入与推理

两模型均 640×640 拉伸、FP32、未 deploy、batch4、CPU 2 线程。保留静态 eval_spatial_size=[640,640]，加载 EMA 时按历史导出程序重建 decoder anchors/valid_mask，再 strict load。Top300、阈值0，不额外 NMS、不先截每类100；交由 COCO maxDets=[1,10,100] 评估。类别0–9，原 GT ID 保持。C 的实际结构是 P2→P3 residual bridge。输入、源码、权重、历史预测与配置逐一记录 SHA256。

二、复现硬门槛

基准采用 data/04_冻结权重诊断_20261001 的 baseline_640_evaluation.json 和 c_640_evaluation.json。两者 AP/APs 各绝对差≤1e-4，全部12项各≤5e-4；这是事前容差，用于 CPU/GPU FP32 差异，逐项交付实际差值。严格加载、每图300条、有限且正宽高、不改权重均为硬检查。失败立即封存，不继续分层判读。历史训练日志中的四舍五入数字不作金标准。

三、GT 分组（仅依赖 GT）

用 FP32 xywh→xyxy→640 拉伸→相减，与349冻结 T/S ID集合核对。T 为 min(w,h)<4；S 为4≤min(w,h)<16。主组 W 为w<4,h≥4；对照 M 为4≤w<8,h≥4。二维描述分段 w/h 共同为 [0,2),[2,3),[3,4),[4,8),[8,16),[16,32),[32,∞)。

四、避免基数效应的主比较

按10类别×高度[4,8),[8,16),[16,32),[32,∞)分层。每层 W/M 各≥20个GT且各分布在≥10张图才纳入。层权重固定为W数量占纳入W总数比例。覆盖需≥80% W并涉及≥2个类别，否则证据不足，不合并/重切分段。统计 delta_recall=(新增TP−丢失TP)/GT，主特异性 D=Σ权重*(W的delta_recall−M的delta_recall)。新增、丢失均从 COCO all-area、maxDet100、同类 IoU≥0.5 的贪心匹配提取。

五、固定统计与通过条件

按图配对 bootstrap 5000次，随机种子20261025，95%百分位区间；空分母重复标为无效，有效率需≥99%。所有条件同时成立才通过：(1)复现硬门槛；(2)覆盖与统计支持；(3)W净召回增益>0且区间下界>0；(4)D>0且区间下界>0；(5)C AP及APs均不低于baseline；(6)S的TP下降≤1%；(7)在已冻结的历史GPU预测上通过/不通过结论保持一致。IoU0.75、二维表、每类表为描述，不进入主判据。其余记 mixed/insufficient 并停，不更换模型、cohort、分段或阈值。

六、训练触发

用户已授权“如果预检通过你自己启动训练”。通过后冻结独立训练清单：baseline640、保持比例832×480、完整C、横向支路640，seed0/1、96轮，同正式配方；横向支路须标明有效stride_y=8,stride_x=4及实际计算量，不能把支路token减半写成整网计算减半。CPU结构/初始化核验和现有远端资源核验后启动，不购买或租用新GPU。不通过则不训练。现有SSH入口不可连接时如实报告，绝不把配置准备写成已启动。

七、解释限制

单seed、按图区间只能描述本配对的关联。宽/高分层不能因果证明横向分辨率，也不能证明跨seed稳定或新颖性。保持原GT id=0与发布口径，披露COCO零ID哨兵局限。只读旧材料，不接触test-dev。

八、交付

冻结协议与计划、执行脚本及SHA、输入清单、GT分组与固定层、两组完整预测、12项复现差值、逐GT匹配证据、新增/丢失ID、宽高二维及每类统计、bootstrap、历史预测敏感性、逐条门槛结果、中文报告、实际调用/优化步数与文件SHA清单。失败时封存截至失败的全部证据。
