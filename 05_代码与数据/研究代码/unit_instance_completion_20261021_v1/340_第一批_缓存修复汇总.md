# 340 第一批：缓存缺口修复（32 张子集）

## 一、修了什么

**1. K_g 网格（340 §一.1）**
- 问题：339 缓存的 K_g 在**整张 640 平面**的 16×16 格（每格 40 px）上散射，与窗无关。
- 修法：`bilinear_scatter_window()` 用窗内坐标 `gx=(cx-x0)/(x1-x0)*16-0.5`、`gy` 同理，格宽 = 窗宽/16（64 px 窗 → 4 px/格）。
- 复现你的例子：image 1、窗 [128,128,192,192]、GT120 中心 (163.7,175.7)
  - 窗内坐标 **row 11.43 / col 8.42** → 非零格应是 **行11/12、列8/9**
  - 339 缓存实际是 **行3/4、列3/4**（正是整图坐标 row 3.89 / col 3.59）
  - 340 修正后：**行11/12、列8/9**，权重 0.3306/0.2444/0.2444/0.1806，Σ=1

**2. RGB128 裁片（340 §一.2）**
- 新增 `crop128_from_window()`，按 296 L45：edge = `(x0+(u+.5)*W_width/128)*orig_w/640`，float32 双线性 border-replicate，RGB/255。
