## 五、必须上报的工程限制（未自行绕过）

**κ_c 在零初始化下检测梯度严格为 0。**
- 311_v2/320_v2 的 `classifier.weight` 与 `box_head[-1].weight` 按 317 §8 规定**零初始化**；
- 因此 step 0 的 `pred_boxes/pred_logits` 与 query 状态无关 → **κ_c 的 loss_det 梯度 = 0**（实测全 10 类为 0.0）；
- 直接对 `generation_plan["residual"]` 反传时 κ_c 梯度非零（如 −0.556），说明算子层通路正常；
- 手动打破零初始化后 κ_c 才有梯度（5 类，~1e−4 量级）；
- 这与 317 §8「不能仅凭零初始化末层让预测天然相同」「若 κ_c 未学动，不能声称已充分排除全局 null 校准」直接相关。
