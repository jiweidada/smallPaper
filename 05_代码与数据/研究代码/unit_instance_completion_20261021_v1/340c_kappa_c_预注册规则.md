# 340c｜κ_c 预注册规则（修订版：原 0.1 档位不可达，已更正）

> **更正**：本文件第一版设「D ≥ 0.1 = 有效学习」。经核算，317 配方下 1218 步的学习率总和仅 **0.06699**，而 Adam 单步更新量不超过 lr，所以 **D 的物理上限就是 0.067**。原 0.1 档位**在训练前就不可能达到**，是一条无效规则。已更正如下。

## 1. 上限核算（可复核）
- 学习率日程：warmup 100 步 1e-5→1e-4，之后 cosine 至 1e-5，共 1218 步（`train340.lr_at`）
- **Σ lr = 0.06699**（实测求和，不是估算）
- Adam 单步更新 |Δθ| ≤ lr·|m̂/√v̂| ≤ lr（偏置修正后该比值 ≤ 1）
- **⇒ κ_c 的最大可能位移上限 = 0.06699**
- 实测速率 1.24e−5/步 → 1218 步外推 ≈ **0.015**（约为上限的 22%）

## 2. 修正后的判定档位（按物理可达范围重划）
| 条件 | 判定 |
|---|---|
| **D ≥ 0.05**（≈ 上限的 75%） | κ_c 接近满速学习，G 臂可作正式对照 |
| **0.01 ≤ D < 0.05** | κ_c 学到但弱，G 臂标注「校准能力受限」 |
| **D < 0.01** | **κ_c 未有效学动**，G 臂标「未有效校准」；R−G 的 4 项不得作为支持 R 的证据 |

**取 0.05 的理由**：0.067 是绝对上限，实际不可能达到（需每步梯度符号完全一致）。0.05 相当于用掉 75% 的理论上限，已是「尽力学习」的合理判据；再往上设就没有判别意义。**这是训练前定的，训练后不得调整。**

## 3. 必须同时报告
- `kappa_c_initial`（应为 0）、`kappa_c_final`（10 维）、`kappa_c_displacement`（10 维）、`D = max|·|`
- `lr_sum_actual`（实际 Σ lr）、`D_over_lr_sum`（D 占理论上限的比例）
- 判定档位

## 4. 本规则不能解决的问题（主控需决策）
**即使按修订档位，317 原配方下 G 臂也很可能判为「受限」或「未有效校准」**：
- 上限 0.067，实测外推 0.015 → 大概率落在 0.01~0.05 的「受限」档，甚至 <0.01；
- κ_c=0 对应 null 参考质量 1，要真正「校准」可能需要 O(1) 的位移；
- 按 317 §7：若 κ_c 未学动，R−G 的 4 项不能作为支持 R 的证据。

**可选方案（均需主控授权，本文件不预设）**：
| 方案 | 做法 | κ_c 位移上限 | 代价 |
|---|---|---|---|
| 1（原样） | 不改配方，按 §2 判定 | 0.067 | G 的 4 项大概率不可采信；12 项门槛实际只剩 8 项 |
| 2（提高 lr） | κ_c 单独 lr ×10 / ×100 | 0.67 / 6.70 | 改配方，需重立 317 版本、全部臂重排；可能不稳 |
| 3（改初始化） | 由数据决定初值 | — | 违背 317「不依 GT/每图统计初始化」，不推荐 |

## 5. 若选方案 2 的前置验证要求
- 先在 32 张子集 CPU 冒烟，逐步记录 κ_c 数值与梯度，确认不发散（无 NaN/无爆炸）；
- 记录 20 步内 κ_c 位移与 loss 是否有限；
- 通过后才可写入 317 新版本并重排全部 run。

## 6. 边界
- 本规则不改变 317 的 12 项方向规则本身；
- 训练后不得因结果对 R 有利而改档位或改阈值；
- 方案 2 的结果不能与方案 1 的 G 直接比较。
