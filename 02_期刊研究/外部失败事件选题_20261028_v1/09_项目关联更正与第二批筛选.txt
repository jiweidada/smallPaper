— 若承接它，需要换验证数据、取得/复现分年模型、补条件标签；它还不是当前任务下的既定问题。原06保留其外部研究价值，不作为项目主线推荐。

第二批E：检测器用于VisDrone-MOT时的跟踪差异。
原文A Unified Framework for Vehicle Detection, Tracking, and Counting Across Ground and Aerial Views Using Knowledge Distillation with YOLOv10-S，Remote Sensing2026，18:842，DOI10.3390/rs18050842。原件KD_YOLOv10_RS2026_18050842.pdf，27页。
Table8：相同OC-SORT框架下，RT-DETR-L IDF1=36.20、MOTA=16.32、IDSW=1420；YOLOv8n=41.81/30.44/854。这个报告有具体数值，但不能单凭它推出“高AP检测器必然更不稳定”。Table3的AP来自不同的DET测试图，作者使用五种车辆相关类别及1344输入、筛选过的图像清单；不是当前十类640协议。§3.4采用默认tracker参数，没有数据特定调参，尚未排除检测分数分布与跟踪阈值的普通解释。原文也没有同MOT帧上的配套检测AP来确认该排序矛盾。
本项目若承接，就要引入视频、身份GT、跟踪/计数目标及新的评价协议；目前没有用户实际跟踪任务需求证据。已有普通tracker/阈值对照尚未厘清，因此不推荐为当前检测主线。没有将RT-DETR结果冒充DEIM结果。

第二批F：所谓复杂背景挑战指标。
FLKFormer: Frequency-Enhanced Large-Kernel Framework for Object Detection in UAV Imagery，Remote Sensing2026，18:1686，DOI10.3390/rs18111686。原件FLKFormer_RS2026_18111686.pdf，20页。
§3.6/Table6使用VisDrone；DINO在AP_bg=26.4，作者方法37.5等数值来自论文。关键条件核查：AP_bg是挑“高目标密度+高小目标占比”的图像构建，没有独立定义背景复杂度。因此这张表可报告该复合子集的性能，不能直接定位“背景复杂造成失败”。没有用数字较低替代独立条件、未混同整体AP与子集AP，也没有据此宣告本文方法无效。未找到更具体的剩余问题，本轮不推荐。

第二批G：ContextShift的D-FINE背景变化风险——保留外部线索，尚不推荐本项目主线。
ContextShift: A Controlled Benchmark for Context Dependence in Object Detection，arXiv2606.09495v1（2026-06-08，预印本），AppendixD.3.1/Table15。
4,952个COCO多目标图像，各配30个自然Places背景，共148,560图像—背景对；评固定focal实例。相对原背景，D-FINE-L AP50 rAUC=0.79，FN/img相对增加57.0%，pred/img下降18.8%，FP/img下降19.5%。Def-DETR rAUC=0.75、FN/img+27.1%。rAUC是归一化曲线面积，不能读成AP下降21pp；相对FN变化也不是漏检率增加57个百分点。该表没有给出可复算的原始FN/FP计数和双seed结果，不能搬成项目实测计数。
这比YOLO固定路口更接近当前解码器家族，但不是当前DEIM配置的结果，输入为COCO合成背景替换，而非已经观测到的VisDrone自然失效群。操作依赖实例轮廓；当前VisDrone标注主要是HBB。默认融合还处理目标边缘、亮度和模糊，不能未经核查就声称只变背景且前景逐像素不变。需要区分真实场景依赖、合成/边缘伪影、目标外观改变，以及数据/模型配置差异。
原文已有context-aware数据增强的直接答案，实际验证模型为YOLO26M：AppendixE Table20中clean AP50由0.877升至0.899（bg_swap），FN/img由0.123降至0.101；Table21相应背景rAUC由0.346升至0.385。这不代表在当前DEIM上已修复，也不能把“D-FINE或本地未测同一增强”当创新。其candidate-existence用输出框IoU>=0.5定义，不能直接推导网络未生成候选，更不据此回到旧定位/排序/名额支线。共享同一前景的30背景对也不按148,560个独立图像解释不确定性。
伙伴核到作者README的multi脚本保留所有多边形分割目标、固定随机focal实例评估，GT沿COCO bbox/segmentation和manifest。A.6/Table8的默认设置为mask侵蚀1px、feather2px、亮度匹配±15%、目标blur sigma0.5。作者blend消融反驳了部分伪影解释；未改COCO原图的关联分组也没有控制对象构成，均不能替代VisDrone自然证据。
最低后续证据需要先明确VisDrone自然条件、对应失败样本及分母，然后才判断是否值得受控背景检验；受控替换若需要可靠实例mask，必须列新增标注/掩码核验工作，不能拿框内保留当干净轮廓干预。所需人工、运行时长和显存均未知，本轮没有执行。外部风险可以保存，当前项目影响与剩余方法疑点仍缺证据。

两批后的取舍：本项目推荐问题卡0张，已支持新方法路线0条。不是证明相关方向没有研究价值，而是这两批尚未得到同时满足“具体失败可信、与当前任务条件可对应、剩余问题值得回答、最低判别成本清楚”的项目题目。不能把固定相机跨年题或COCO背景操作改名后当成VisDrone/DEIM已存在的问题。

本轮缺少的关键证据：
1. 本项目内可操作、能与尺寸/密度/可见性分开的真实使用条件，而不只是泛泛“复杂背景”。
2. 在该条件下当前模型相对合适参照的实际失败与影响；外部模型结果只能作线索。
3. 排除最强普通处理后仍会改变研究取舍的疑点，不能靠尚未本地测过宣称方法空白。
4. 若需要视频、跨年或实例掩码，真实资源与任务变更成本；未知时明确未知。

没有新模型前向、训练、重评、profiling或本地数据统计；只是原文、代码/配置和公开元信息阅读。原始研究目标仍是本项目选题，不用以上未成立候选包装为找到主线。
