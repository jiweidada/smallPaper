## 3 线程 0：论文现在声称的问题，与证据支持到哪一步

**Q0.1 论文的问题是"信息内容在 fine→coarse 传递中是否有用"，还是"检测在什么条件下失败"？**

前者。main.tex:85 的动词是 study whether ... improves（问收益是否存在），main.tex:87 把实验问题
限定为 access to within-cell differences；main.tex:49 明确排除"连接图案的优先权"；main.tex:51 说
"只和 baseline 比不能回答这个问题"，因此设计了 C vs C-mean 的训练期限制对照。全文没有一句把
"检测在何处失败"设为主问题；失败只在 main.tex:319（尺度权衡，medium/large 掉点）和
main.tex:417（宽度误差例外）以"解释边界"的身份出现。

**Q0.2 现有证据回答的是哪一个？**

前者。C − C-mean 的 APs 差 val 0.449–0.729 pp、test-dev 0.163–0.837 pp（main.tex:295），
rank16 − rank16-mean 三 seed 两 split 全正（main.tex:311），成本 +17,440 参数（0.170%）、
+1.031% FLOPs（main.tex:349 表格）。这是一个**受控信息限制实验**：同一名义架构、同参数量、
只去掉四相位差。它证明的是"保留子格内差异在这个紧凑通路里可测地有用"，不是"检测器在什么条件下
失败"。

**Q0.3 如果问题属于"信息有没有用"，还需不需要一个方法创新？**

不需要，而且加方法创新会**换掉问题**。证据链已经闭合：信息组分被单独隔离（C vs C-mean）、
维度被单独控制（rank16 对）、成本被记账（17,440 参数）、跨数据集做了同向复现（UAVDT，354）、
边界被写出（medium/large 掉点、宽度误差例外）。剩下的是"这个结论在哪些设定外推"的实证工作，
不是"还缺一个模块"。

**判定：论文当前问题 = 实证型（empirical）。**

推论（写作层，不是技术层）：本稿不能"加创新点"变成方法论文；若要走 B 路径，只能**另立一个
问题**写成另一篇论文——两篇不许混着写。这一条约束下面 §8/§9 的定级。

## 5 线程 2：机制分解

### 5.1 判别一：Geo0 的框形（形状 vs 尺寸）

**两套宽高比（Geo0，n=3,715 / 3,727）**

| | p10 | p25 | p50 | p75 | p90 |
|---|---|---|---|---|---|
| 原始分辨率 w（px） | 4.0 | 5.0 | 6.0 | 7.0 | 8.0 |
| 原始分辨率 h（px） | 6.0 | 8.0 | 13.0 | 18.0 | 22.0 |
| 原始 w/h | 0.282 | 0.333 | **0.421** | 0.588 | 1.000 |
| 640 平面 w（px） | 1.882 | 2.353 | 2.824 | 3.333 | 3.764 |
| 640 平面 h（px） | 5.020 | 7.530 | 11.713 | 15.059 | 18.405 |
| 640 平面 w/h | 0.159 | 0.188 | **0.237** | 0.331 | 0.562 |

原始分辨率占比：w<4 = **16.53% / 16.47%**，w<8 = **96.5% / 96.43%**，w<16 = 100%；
h<4 = 2.29% / 2.31%，h<8 = 19.81% / 20.04%，h<16 = 66.08% / 66.86%。

**判别结果：形状不是成因，宽度像素数才是。** 三条证据：

1. **组间对照**：tiny 里已被覆盖的 1,237 / 1,225 个目标，原始 w/h p50 = 0.437（Geo0 是 0.421），
   640 平面 w/h p50 = 0.246（Geo0 0.237）。形状几乎一样，成败不同 → 宽高比不区分成败。
2. **分箱非单调**：按原始 w/h 分箱的失败率是 80.06/79.17（<0.35）、72.12/71.44（0.35–0.5）、
   67.72/69.47（0.5–0.75）、77.16/80.05（0.75–1.0）、87.40/89.86（≥1.0）。最方/最宽的一组
   反而失败率最高（87–90%），细长组不是最差。
3. **分箱单调**：按 640 平面宽度分箱是 96.83→87.45→76.39→67.30→64.55（两 seed 同序），
   跨度 32 pp。

**检出力**：最小分箱 n=365（w/h≥1.0）、n=536（640 宽 <2px），单箱比例的标准误 ≤2.6 pp，
而观察到的最小箱间差是 20 pp（w/h 0.5–0.75 对 ≥1.0），是噪声的 7.7 倍。**这个检验有能力
发现 10 pp 量级的形状效应，实际没有发现**——所以"长宽比不解释失败"是一个有检出力支撑的阴性，
不是"没查"。

结论：**"各向异性拉伸导致横向定位难"不成立**。640 拉伸确实把 2.4:1 压成 4.2:1（0.421→0.237），
但细长不是失败的原因，失败跟着"目标宽度只有 2–4 个像素"走。§7 的问题陈述因此不许写"各向异性"。

### 5.2 判别二：无近邻样本是"没框"还是"框在远处"

对象：口径②未覆盖的 2,472 / 2,420 个 Geo0（其中图内有同类 query 的 2,444 / 2,378，
完全无同类 query 的 28 / 42 = 1.13% / 1.74%）。

| 指标 | seed1 | seed2 |
|---|---|---|
| 最近同类 query 中心距 p25 | 17.99 px | 17.85 px |
| p50 | 39.81 | 40.10 |
| p75 | 80.88 | 80.22 |
| p90 | 133.21 | 133.27 |
| ≤16 px 占比 | 22.50%（550） | 22.16%（527） |
| 16–32 px 占比 | 20.09% | 20.06% |
| >32 px 占比 | 57.41% | 57.78% |
| 最近框中心落在图像内 [0,640]² | 100% | 100% |

| ≤16 px 组分数 p50 | 0.1914 | 0.1816 |
| >32 px 组分数 p50 | 0.1999 | 0.1801 |

**把两种成因分开报占比**：

- **覆盖问题（>32 px）**：57.41% / 57.78%。最近同类框在 32 px 之外；以 Geo0 的 GT 高度中位
  11.7 px 计，这是 2.7 个目标高度以上——不是这个目标的框。
- **邻居/邻实例（≤16 px）**：22.50% / 22.16%。但用归一化距离（dist / GT 高）看，这一组里只有
  **23.09% / 21.25%** 落在 0.5×GT 高以内；全体未覆盖者的 dist/GT 高 p50 = 3.60 / 3.62，
  ≤0.5×GT 高的仅 5.20% / 4.71%。所以"16 px 以内"并不等于"这是同一个目标的框"。
- **排序问题（分数被砍）**：**未观察到，但该检验对本数据零检出力**。原因不是"分数不低"（远近两组
  分数分布几乎重合，p50 0.19 vs 0.20，说明远框不是被分数压下去的），而是**缓存结构**：
  342 缓存每图只保留 300 条（final300_boxes 与 fullp_boxes 同一组框、两种参数化；fullp_boxes 是
  像素 xyxy，final300_boxes 是归一化 cxcywh，逐行核对数值一致），**被 300 上限截掉的 query 在
  缓存里不存在**。因此"是否存在一个高 IoU 的同类框被 300 上限挤掉"这个问题，本缓存**不可测**。
  要测它必须重建带全 query 的缓存（模型输出 900 query），可测但本轮未做。

**判别**：≤16 px 且分数被压 → 排序问题，**没有这样的样本**；真正成立的是 57.4–57.8% 的覆盖缺口
（框在远处），加 22.2–22.5% 的邻实例混淆。两者对方法方向的指向完全不同：前者要改 query 分配/密集
化，后者要改有效分辨率。

### 5.3 三分解（A/B/C，两套定义）

分母 3,715 / 3,727。A = 窗口内无 query；B = 有 query 但未过阈值/后处理；C = 有 query 且分数够
但 IoU<0.5。

| 半径 | 情形 | seed1 | seed2 | 判定 |
|---|---|---|---|---|
| r=8 | A 无 query | 624（16.80%） | 715（19.18%） | — |
| r=8 | B 字面（最高分 <0.001） | **0（0%）** | **0（0%）** | 零检出力，见下 |
| r=8 | B 后处理条件（最高分 query 未进 fullp_query_index） | 457（12.30%） | 449（12.05%） | — |
| r=8 | C 存活但 IoU<0.5 | 2,634（70.90%） | 2,563（68.77%） | **mixed**（seed2 <70%） |
| r=16 | A / B / C | 5.41% / 7.24% / 87.35% | 6.31% / 6.63% / 87.07% | mixed |
| r=32 | A / B / C | 0.81% / 1.80% / 97.39% | 1.56% / 1.77% / 96.67% | mixed |

两条必须写明的性质：

1. **B 字面恒为 0，是数据结构的必然，不是发现**。缓存里每图恰好 300 条、最小分数 0.00358 /
   0.00308，全部 >0.001 阈值 → 按提示词定义的"分数低于阈值"这一情形在本数据里**在构造上不可能
   出现**。该检验对"阈值砍掉"的检出力是 0，不能据此说"阈值不是问题"。真正的 B（后处理条件）
   是 12.30% / 12.05%，指的是"窗内最高分 query 没进最终 300 条"——而"没进"本身就是被 300 上限
   截掉，与 5.2 的不可测问题同源。
2. **C 是构造性成立**。入组条件已保证这 3,715/3,727 个 GT 在 300 条输出上全类 IoU<0.5，所以
   窗内任何 query 必然 IoU<0.5。C 的占比只说明"窗口内有 query"，**不指认任何成因**；v1 里
   "C 主导 ⇒ 回归/分配是主因"的推论已作废。

按提示词的判据（某情形 ≥70% 才算主导，否则记 mixed）：r=8 时 seed1 70.90% 刚过线、seed2 68.77%
未过 → **记 mixed**，不批准"某一情形主导"的结论。

### 5.4 反事实替换

## 6 线程 3：边界（问题在什么范围内成立）

### 6.1 输入形状：640×640 拉伸 vs 832×480 保比（复用 349/350，未重跑）

| 组 | TP 变化 | APs | S 组 TP | 判定 |
|---|---|---|---|---|
| T（832×480 等像素保比） | +141（seed1）/ +40（seed2） | −0.006293 / −0.008513 | −1.40% / −4.53% | mixed，停 |

解读：换了输入形状，**TP 是涨的、APs 是跌的**——说明"检出更多"与"排序更好"不是一件事，
而且 H2 的机制（有效像素）与 APs 的方向对不上。同像素下 640 拉伸的 tiny 计数 5,096，保比后按
800×512 / 853×480 / 960×540 分别是 2,531 / 2,669 / 1,430（4.24，纯标注算术，不动模型）——
**同一批目标在保比口径下有一半不再属于 tiny**。所以"tiny 的失败率"本身是口径的函数，这一点
必须写在论文里，否则数字不可比。

**边界结论**：现象在 832×480 保比下没有消失（TP 涨、APs 跌、S 组跌），也不因换成保比而加剧到
可判定；**输入形状不是该现象的开关**。

### 12.2 A 路径的写作边界（避免越界成方法论文）

1. 不许把 F1–F8 写成"因此需要一个新模块"。它们只回答"失败在哪里、有多大、边界是什么"。
2. 不许把 4.10/4.11 的 oracle 写成可实现收益（348 的行文已明确"上界诊断"）。
3. 不许写"现有方法都不行"。计数是 5 篇/3 篇/1 篇，且本地未测；正确写法是"现有解覆盖这一类，
   其在本设定下的残余未测"。
4. F4 的 66.5% 不能写成"三分之二的 tiny 目标被漏检"——Geo0 的定义是"无 IoU≥0.5 的输出"，
   不等于漏检；同类 IoU≥0.1 的有 33.5%，任意类有 69.4%。

### 12.3 若要继续做实验，唯一被本文件允许的方向

**重建带全 900 query 的缓存**（改 342 缓存脚本，保存选择前的完整 query 集）。它能一次性回答
两个当前不可测的问题：（a）被 300 上限截掉的同类高 IoU 框有多少（§5.5 的证伪观测）；
（b）B 字面情形是否真的为空。成本是一次推理 + 改存字段，不训练。**这是唯一能把闸门 2 从
"不过"变成"过或不过有数"的动作**；在此之前，任何方法提案都建立在"不可测"之上。
