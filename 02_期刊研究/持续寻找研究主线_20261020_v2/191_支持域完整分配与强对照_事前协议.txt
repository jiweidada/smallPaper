二、约束与目标
对每图每类，固定原 G0 的 query 集合 Q、每 query 原目标类别、每 GT 多重预算 m_g。每 q 恰好分给一个同类 GT，每 g 恰好接收 m_g 个不同 q；未在 G0 中的 GT/query 不进入。ordinary 的 m_g=1；GO 可 m_g>1。GO 几何所有权不冒充 MAL own 正类槽，ordinary MAL/GT 分母和 GO 几何分母分别报告。
由真实初始 ref=(cx,cy,w,h)、R=abs(reg_scale)、GT 两角，计算未 clip 的四边 d*：dL=(cx-x1)/(w/R)-R/2，dR=(x2-cx)/(w/R)-R/2，纵轴同理。实际 FP32 native weighting_function 的端点 a,b 构成闭支持。F=all(a<=d*<=b)。有限 softmax 的端点仅按闭包可达，不声称有限 logits 能精确到端点。主域使用 FP32 缓存坐标转 FP64 后上述无 eps 的物理逆式；真实 FP32 bbox2distance 在 clip 前的支持另报，不把其分母 1e-16 当物理解码公式。
v(q,g)=sum_k[max(a-d*_k,0)+max(d*_k-b,0)]/R，先按规定 FP64 算每边 v，再将这个有限二进制数精确整数化；没有声称消除了前面 FP64 运算舍入。
G：依次最小化 sum(1-F)、sum(v)、sum(Cfinal)。Cfinal 完全沿当前 native final matcher 的 FP32 focal-class/L1/negative-GIoU 权重 2/5/2，matcher alpha=.25 gamma=2；不是 MAL gamma=1.5。代码直接提取原 matcher 类、仅对缓存调用 matcher，并捕获其给 SciPy 前的实际 cost，不手改运算顺序。相同类别的 class 项在实数公式中为每 q 常量，但 FP32 合成 cost 仍按原值保留，不假称它提供了新的类别自由度。
强控制 I：max sum(final IoU32)，在其精确最优 face 内 max sum(F)。
强控制 R：max sum(initial-ref IoU32)，在其精确最优 face 内 max sum(F)。
强控制 C：min sum(Cfinal)，在其精确最优 face 内 max sum(F)。
G0：原 ordinary own / 本次原 GO，完整保留。
各求解臂在上述目标完全相等后再最少改变 G0 owner；再有并列，以固定版本 NetworkX、排序节点/边确定性求解，不声称最后是全局 ID 字典序最优。普通 SciPy -IoU 原控制另存，用于量化 184 的任意并列部分。

三、精确性与见证
每个有限 float 用 as_integer_ratio() 转为分母 2 的幂的整数，按每级最大分母共同缩放。每行减最小值不改变所有完整分配的排序。该级所有分配的非负整数总值界为 U=sum_q max_g shifted_cost(q,g)。从高至低递推 packed=packed*(U_next+1)+next；上一级差至少 1，所有下级合计不足相应进位，严格保持 lex priority。全部供需、capacity、weight 都是 Python int；不用 epsilon、不用 float SciPy 解大整数、不将 machine-float 总和相等称为 exact tie。
NetworkX 3.3 network_simplex 解每类整数运输。输出完整 q->g、每级整数分母/分子与范围界、packed cost、最大 bit 长度。另从所选解构造精确整数运输对偶：对每个已分配 q->g，约束 p_h-p_g<=cost(q,h)-cost(q,g)；Bellman-Ford 得到 p 后 u_q=cost(q,g)-p_g。逐边验证 u_q+p_h<=cost(q,h)，并验证 primal cost = sum u + sum_g m_g p_g；无精确证书则实现 failclosed，不能报方法阴性。
先合成、后缓存内容：测试多级优先级不被巨大下级破坏、2^-80 级别差不被 epsilon 吞掉、同一 GT 接收多 q、固定同类槽/多重预算、非同时接管反例、支持最优 face、完整分配、native 闭支持/非法宽度。小例穷举所有合法完整分配与整数流结果相同。沿用 183 的原生编码审计，复用文件全部 hash 固定且不调用旧 main。
