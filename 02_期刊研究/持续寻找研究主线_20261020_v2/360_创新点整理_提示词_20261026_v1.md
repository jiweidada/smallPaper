- 类型只能是三种：

- 状态只能是：成立 / 弱支持 / 阴性 / 停止 / 未验证。

必须遵守：
- 不许把"相对 C-mean 为正"写成"相对 baseline 为正"。C 线在 UAVDT test 上相对 baseline 是负的

  "首次四相位 P2→P3 传递"、pixel_unshuffle 是新算子、固定排列顺序有新颖性、
  "均值已被证明冗余"、"只补横向分辨率"、"DC 可删/只传细节"、

## 3. 线程 B：从 C 类里抢救真方法创新

### 3.1 先给每个 C 打停止原因标签（二选一，不许两个都写）

- **C-1 证据不足**：现象在本机没出现，或工程门槛没过，但近邻文献没有解决这个问题。
- **C-2 近邻已覆盖**：现象可能真实，但直接先例已有等价方法。
- **C-3 双重否定**：两者同时成立（如 358 本地没过 + 查新撞车）。

判定只认两样：停止时写的门槛/事件数/复现结论；查新记录里的**具体论文 + 章节或公式**。
查新记录没写具体章节的，一律算"未查"，既不算 C-2 也不算 C-1。

然后：
- C-2 → 写明被哪篇的哪个公式/算子覆盖；除非我能指出该文没有要求的东西，否则不再讨论。
- C-3 → 直接划掉，不救。
- 只对 C-1 继续往下写。

### 3.2 每个 C-1 按七栏写满（任何一栏写不出 → 降为"不立项"）

1. **现象**：停止时手里那组数字（事件数 / 分母 / 门槛），并明确它是不是"几何候选"而非 TP。
2. **为什么不是"没训好"**：区分"我们的配方没学到"和"这个问题不存在"。
3. **与直接先例的差异**：一句话说清差异落在【算子 / 目标函数 / 推理约束】哪一项。
   三项都对不上就写"不成立"。**禁止靠改名包装**（"证据记忆""时序重评分""冷启动定位"这类）。
4. **最小核查**：只用现有资产（BASE24、第36轮六份 EMA、C/C-mean/rank16、各类缓存），
   CPU 可跑，写明预计耗时与要读的文件清单。不 new 训练、不跑 GPU、不碰 test。
5. **预注册门槛**：写死数字与停止条件，必须比 358 更严——
   "只在一个序列上成立""只在描述模型上成立""换阈值才成立"一律算不通过。
6. **如果通过，训练要花什么**：几组配对、几个 seed、哪个数据集、GPU 量级。
7. **最有可能让我白花这笔钱的反驳**：一句"审稿人或我自己的哪条数据就能否掉它"。

### 3.3 线程 B 只允许两种输出

- **(a) 0 项 C-1** → 直接写"按 356 的 A 路径收尾，不做新训练"，并用 358 的结论说明为什么不该继续找。
- **(b) ≥1 项 C-1 且七栏写满** → 只推荐 1 项，其余列出"为什么不选"。

最后必须回答一句：如果这次仍全部失败，是否说明 356 的 B 路径在这批资产上不可行。
不许为了给 B 一个交代，降低 358 已写死的标准——"与直接先例可区分的算子/目标/推理约束"。
