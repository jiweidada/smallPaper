316｜C：固定几何解释对照及完成条件核查
2026-10-21。创建前确认316编号未占，315留给A。只读309原文核查、313共同材料、301结果复核、292协议及299的geometry_cost/conditional/cap_once定义，依据主控回交的Claude新建议与新增null校准问题作设计判断。没有读取新预测、重算oracle、运行代码/训练或访问heldout/远端。306/304历史三臂提案不改，本文明确提出训练前版本修订。

决定：现在应采用N/S/G/R四臂，而非维护三臂数量。G选“固定几何cost＋可训练每类null偏置”，不是center kernel/noNull，也不保持κ永远为0。每类κ_c共10个标量、初始化0、由G正常检测loss训练；公共可学习Cθ/κθ的关联辅助分支及loss照常保留。这个选择只强化同一个G，不新增第五臂。它能直接面对固定密度衰减和简单null校准这个新替代解释；仍不把所有疑问打包成无限前置实验。

一、新原文为什么改变对照理由
309已核2025 Density-based Object Detection in Crowded Scenes的部署Eq9：选定框b_t后，d_i←d_i exp[−IoU(b_i,b_t)^2/σ]，再参与现有proposal筛选。2015 Small Instance Detection by Integer Programming on Object Density Maps则已由单位密度恢复位置并估框。因此“看到旧框后降低密度，再由密度产生框”不能单独立新；减法与乘法也不是边界，因为r=m−min(m,u)可写成m乘非负剩余比例。
但这不等于两篇已逐式实现当前R：2025的d_i属于已有proposal，2015处理全部整数位置恢复；当前是同一含错P下的类别质量、单位解释/null与自然补集新生。原文差别允许形成具体候选，不能替代强控制。
原三臂即使R胜N和S，仍可能只是固定几何衰减先验比自由set attention更容易在六轮内使用，而非学会了按内容拒绝错误解释。G正好隔离这个替代解释。原文补足发生在首次训练前，修改核心比较有实质理由，不是看到训练结果后救R。309原建议维持三臂可以修正，不能把先前结论当不可更改的门槛。

二、为何不用center-K1/noNull/noScore作为主强控制
固定中心核需另定带宽、截断与归一方式；一个条件框包含遗漏中心，不保证其中心核在该处有足够质量。因此284的c类共存不能推出这种核必定误扣，更不能借一个可能几乎不触发的核制造R优势。特别是预测类别错误时，类内解释根本不扣真实类别质量；“框盖住了GT”不是扣量证书。
删除null也改变单位供应和解释自由度，使控制弱于已经存在的I_cap。主G应沿同m参考、同类连接、同ε=1、同rowcap/退null及同残余读取，仅固定cost为同一d_out。这样不用新核或新幅度，且实际检验一般几何解释能否复制效益。

三、锁定G：固定几何，加最小可学习类别null校准
令mbar=sg(m)，只连条件j的预测类c_j；位置x_i和未clip预测框b_j沿296/306：
  d_ij=max(x1_j−x_i,0,x_i−x2_j)/w_j
       +max(y1_j−y_i,0,y_i−y2_j)/h_j。
G的生成计划为
  K^G_ij=mbar_{i,c_j}exp(−d_ij)，K^G_0j=exp(−κ^G_{c_j})；
  p^G_ij=K^G_ij/(K^G_0j+Σ_lK^G_lj)，p^G_0j=K^G_0j/(同分母)；
  u^G_ic=Σ_{j:c_j=c}p^G_ij，a^G_ic=min(1,mbar_ic/u^G_ic)，u=0取1；
  T^G_ij=a^G_{i,c_j}p^G_ij，z^G_j=p^G_0j+Σ_i(1−a^G_{i,c_j})p^G_ij；
  r^G_ic=mbar_ic−Σ_jT^G_ij=(mbar_ic−u^G_ic)_+。
κ^G为10个不依图像、实例或score的自由实数；全部初始化0、采用共同学习率/clip规则、作为bias不做weight decay。只由G的正常L_det学习，不加新标签、专门校准loss、val拟合或逐图估计。N/S/R的现有参数、公式和loss不因增加G而改变。
它允许一个全局null校准作为所有κ_c相等的特例，也允许各类不同校准；不能只因G不曾调整拒绝强度，就把R的收益归为候选级拒绝。对固定m/d，有∂p^G_ij/∂κ_c=p^G_ij p^G_0j（同类），所以严格未饱和行的∂r^G_ic/∂κ_c=−Σ_j p^G_ij p^G_0j。该类可以学习整体多解释或少解释，不能单独拒绝同类中的某个错误候选。κ→负大时趋向退null、保留m，因而G也能趋向忽略几何条件。
严格过载行的残余导数为0，折点子梯度依实现。若κ_c整个短训都因饱和没有有效梯度，必须如实报告，不能宣称已经穷尽排除所有全局校准；但不为此事前新增oracle或第五臂。这个限制同样不能被当作“G不能学习”的定理，未饱和位置及后续m/共享特征变化均可能提供路径。

不选“共同aux κ输出按类平均后detach”：它随图像/候选组成变化，已借入学习到的外观及score信息，且平均范围、空类和跨batch状态还需额外定义。它并非简单的全局/每类校准，R−G的语义反而不清。10个直接标量是更小且可审的控制；当前不同时保留多个G版本择优。

四、G必须有两条明确计划，不能把辅助loss接错
所有臂共同的trainable辅助计划仍是
  (T_aux,z_aux)=cap(mbar,Cθ(P,f),κθ(P,f))，
共同L_assoc仍根据同M0作用于T_aux/z_aux。N、S不把该计划送入生成；R把它的残余送入生成。G另外用上述d_out/κ^G计算r^G，送入完全相同的类别value和总量attention bias。
不能为了“G是固定解释”把它的L_assoc换成固定G计划：那会改变监督途径，并在mbar被detach时使原Cθ/κθ失去共同训练信号。也不能把G的κ^G接到额外GT null目标后仍称只有检测loss校准。两条路径的作用与参数须在实现中明确命名。
G生成不显式用score加权，但P本身仍来自同score阈值/top300；公共关联训练也使用同15维含score输入。因此不能笼统写成“G完全没有score信息”。所有arm的局部RGB、m、辅助loss、M0补集、四query、输入曝光、原生融合与整体GT预算都相同。
R−G仍是包级差异：可学习图像/候选cost、候选级null以及它们进入生成后的检测梯度，相对于固定几何＋每类校准；不能据其正值单独宣布“κ识别FP成功”或“某个单模块有因果效益”。它至少排除了κ永久0这个明显更简单的解释。

五、300已经提供了什么，为什么不再索要oracle表
已亲读299：geometry_cost正是上述逐轴框外距离/wh和，conditional是m exp(−C)加κ=0的null参考质量1，cap_once是一趟容量截断及超额退null。因此300的I_cap确是G在κ^G=0时的同式算子特例；现有合成与真实缓存已经支持其可计算、可行且不只是“无定义的新设想”。
边界必须保留：300使用GT oracle m、旧centre供给和已冻结增强窗；本G使用预测m、新intersect供给和待采自然图，κ_c还将学习。300不是G新头的真实效果，也不能用其J−I_cap差值证明G好坏，更不能将旧计数重命名为新M0数据。
再画一张GT-m oracle表不能判断可学习R是否胜可学习G，且当前没有需要这张表解决的数学未定义处。最小新增无训练工作只是在已有311原型上接G，并验证两项接口：
  1) 初始化Cθ=d_out、κθ=0、κ^G=0时，R/G残余、hidden states和预测一致；不能仅依低分/零框头让输出parity天然成立。
  2) 固定同m/P，改变θC/θκ只改变G的aux计划而不改变G生成计划；改变κ^G在预定未饱和合成例中确有生成梯度，在严格饱和例中按实际算子报告零。无P时仍保留m。
其余列守恒、行界、empty/padding、m detach/共享f梯度等沿已有合同，不重建一套自然数据资格清单。本轮只写建议，不修改或执行311。

六、选择四臂及具体成本，三臂只能回答更窄问题
推荐一次N/S/G/R四臂：N回答同crop/密度/补集训练本身；S回答普通逐实例条件集；G回答固定几何解释加类别校准；R是待检验自适应解释。新增文献让G成为具体强替代，不能仅为保住“三”而撤掉S，退回缺乏一般集合控制；也不宜撤掉N后再声称条件机制对无条件局部头有增量。
若算力绝对只容许三臂，S/G/R能回答结构化自适应是否胜两个条件控制，却不能完成当前含N的完整效益归因；应如实收窄目标，而非让它自动代替四臂结论。当前优先一次四臂，避免先跑旧三臂再用见结果的方式追加G。
原每run六轮/1218步/19410crop不变。四臂双seed变为48个head epochs、9744 optimizer steps、155280训练crop曝光；比36轮多12轮、2436步、38820曝光。公共冻结raw缓存6470次全局forward与末评1096次全局forward可共享，不因G增加；G自己的训练/末评head计算与分析费用必须新增，不是零成本。
G部署可删仅供辅助的可学习association分支，只留m、几何计划、10个κ和decoder；训练仍含共同aux加一条G计划。参数/FLOPs/墙钟应分别记训练与部署，不能用相同epoch声称相同算力。当前没有这些新增实测成本，不虚构GPU小时。

七、完成条件应随真正对照更新，不用共识或oracle结束主线
若沿306的机械方向规则，加入G后应把R−G也纳入同等主比较：两seed×三control(N/S/G)×两个指标(APs、tiny Geo0新增TP@.5)，共12项严格正才记该有限学习方向保留；不是原8项过了、G再只作描述。正式v3须在训练前锁定这个修改，不在训练后选择对照或阈值。总体AP、FP、原TP损失及成本仍全部披露，方向通过不等于净效益、显著性或发表成立。
若G复制R，即使R胜N/S，也只能支持一个更简单的几何密度补全方案，不能继续以候选级自适应解释作实质增量。若R胜G但不胜S，通用条件集合已足够，不能以学到null为由抬高贡献。若R同时胜N/S/G且有真实新几何，才支持进一步投入；仍需按配对不确定性与实际代价判断，不把微小正数包装完成论文。
当前“具体可审”可由四臂定义、最小G合成接线及真实预算完成；“主线已验证”必须等待授权后的固定学习结果，不能由311合成可导、300 oracle差异或专家支持替代。无需继续索要一张不能回答学习比较的新oracle表，也不因为尚未训练就否定该候选值得一次有限验证。
