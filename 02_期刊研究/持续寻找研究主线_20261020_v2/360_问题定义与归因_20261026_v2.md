## 3 线程 0：论文现在声称的问题，与证据支持到哪一步

**Q0.1 论文的问题是"信息内容（子格内差异）在 fine→coarse 传递中是否有用"，还是"检测在什么条件下失败"？**
前者。main.tex:85 的动词是 study whether ... improves；:87 把实验问题限定为 access to within-cell differences；:49 明确排除"连接图案的优先权"；:51 说"只和 baseline 比不能回答这个问题"，因此设计了 C vs C-mean 的训练期限制对照。全文没有把"检测在何处失败"设为主问题；失败只在 main.tex:319（尺度权衡）与 :417（宽度误差例外）以解释边界的身份出现。

**Q0.2 现有证据回答的是哪一个？**
前者。C − C-mean 的 APs 差 val 0.449–0.729 pp、test-dev 0.163–0.837 pp（main.tex:295）；rank16 − rank16-mean 三 seed 两 split 全正（main.tex:311）；成本 +17,440 参数（0.170%）、+1.031% FLOPs（main.tex:349 表）。这是受控信息限制实验，证明"保留子格内差异在这个紧凑通路里可测地有用"，不回答"检测器在什么条件下失败"。

**Q0.3 若问题属于"信息有没有用"，还需不需要一个方法创新？**
不需要，加模块会换掉问题。证据链已闭合：信息组分被隔离（C vs C-mean）、维度被控制（rank16）、成本被记账（17,440）、跨数据集同向（UAVDT，354）、边界被写出（medium/large 掉点）。

**判定：论文当前问题 = 实证型（empirical）。**
推论只限写作层：本稿不能"加创新点"变成方法论文；B 路径只能**另立一个问题**写成另一篇。**该判定不构成对任何新问题的否证**（E13）。

**判别结果（修正 v1）**：

1. **方向与"被压扁"假说相反**。同一宽度段内，w/h≥1（更方/更宽）的一组失败率最高（0.837–0.959）；w/h<0.5（窄高）的一组反而最低（0.540–0.796）。若横向压缩是主因，窄高组应最差。

3. **组间对照仍成立但只能作旁证**：已覆盖 tiny 原始 w/h p50 = 0.437，Geo0 = 0.421，两者形状接近；但两组尺寸不同，不能单独承担因果结论。
4. **检出力**：单变量分箱里最小箱 n=365、比例标准误 ≤2.6 pp，最小箱间差 20 pp 是噪声的 7.7 倍；二维层里最小有效箱 n=123（≥1 组），标准误 ≈4 pp，而 ≥1 组与 <0.5 组的差是 8–15 pp，可检出。所以"未检出独立形状效应"是有检出力支撑的阴性，但**阴性不等于无效应**（E5）。

**结论**：main.tex:87 对四相位差的定义不受影响；但本文件**不再写**"各向异性拉伸不成立"，改写"各向异性作为独立成因未被检出，且现有数据无法把它与面积分离"。

### 5.2 判别二：Geo0 是"没框"还是"框不达标"（修正 v1）

v1 用"最近同类 query 中心距"来分"没框 / 框在远处"，这是**错的**：那个距离是最近 query 的，不是候选框的（E4）。正确做法是直接在 300 个 query 上算同类（argmax 类）最大 IoU，然后按阈值切：

| 组（tiny Geo0，n=3,715 / 3,727） | 定义 | seed1 | seed2 | 解读 |
|---|---|---|---|---|
| 同类 IoU ≥0.5 | 有合格框 | **0** | **0** | 结构性为零：只要存在这样的框，该 GT 就不满足 Geo0 定义 |
| 同类 IoU 0.1–0.5 | 框在、但不达标 | 1,243（33.46%） | 1,307（35.07%） | 这正是口径②的"已覆盖"集合 |
| 同类 IoU <0.1 | 附近没有同类框 | 2,472（66.54%） | 2,420（64.93%） | 口径②的"未覆盖"集合 |

**判别的正确结论**：

- **Geo0 里不存在"框被预算丢掉"的情形，一个都没有**。原因不是运气，是定义：Geo0 用的是 300 个 query 的**全部**框，而"合格候选被 top300 丢掉"的 2,359 / 2,392 个 GT 必然有 IoU≥0.5 的框，因此**必然不属于 Geo0**。用户指出的"145 个 tiny 丢失不属于 Geo0"就是这个恒等式的特例，本轮在全部 tiny 上验证为 0。
- 所以 Geo0 的 66.5% 未覆盖 = **同类框根本没到 0.1**，不是"框在远处"（v1 的 39.8 px 不可用），也不是"排序砍掉"（结构上不可能）。
- 这与 4.3 一致：Geo0 里有任意类 IoU≥0.1 的占 69.4% / 66.1%，其中多数是**异类**框——即"框在，但类别/位置都不对，且同类框不存在"。

### 5.5 机制命题（可判定，带证伪观测）

> **在 640×640 拉伸、每图 300 个 query、VisDrone val548 的设定下，Geo0（短边<4 px 且 300 框全类

## 8 线程 5：问题陈述与规格

### 8.1 问题陈述

**P5（唯一通过闸门 1–3 的问题）**
「300 条目预算下 2,359/2,392 个合格 GT 丢尽同类条目，62% 被同 query 异类占位，851/858 无框覆盖；argmax 少 11% TP、类内 NMS 仅补 1.1%。」

四成分：条件 = 300 条目预算 / val548；失败 = 2,359/2,392 个 GT 丢尽候选、851/858 无任何框覆盖；成因 = 62% 同 query 异类占位、38% query 未上榜；未解 = argmax 与 NMS 都有量化缺口，AP 未测。

**描述性事实（不构成待解问题，只作边界与素材）**

- D1 尺寸梯度：640 平面短边 <4 px 的 75.0% 无 IoU≥0.5 输出，失败率随短边单调 96.8%→64.6%（4.19/4.21）。
- D2 宽度过估：口径② 1.702/1.764（+0.7025/+0.7642），±1px 13.68%/12.09%；口径① +0.7437/+0.8093、17.03%/14.82%。
- D3 覆盖缺口：Geo0 里 66.5%/64.9% 同类最大 IoU<0.1（5.2）。

（D1–D3 的"最小可行解"分别是 SAHI/LiG-DETR 与 NWD/Sized-L1，均为已有技术 → 按 §8.3 属 A 路径素材。）

### 8.2 由 P5 推规格（预设判据，非文献门槛）

1. **有效**：同协议（val548、同 ckpt、检测数仍为 300）下，851/858 的"无框覆盖"降到 **≤300** 为支持；≥600 为否掉。
2. **不靠 FP 换**：全体 GT 的几何 TP 不减（≥23,684/24,311），且"该类无 GT"的框（nom）相对原后处理增幅 **≤5%** 为支持；>15% 为否掉（NMS 实测 +27.9%/+32.0%，即已越线）。
3. **AP 不降**：val548 原协议（maxDets、score 门槛、匹配口径全部冻结）下 AP 与 APs 均不下降；这是唯一终判据，几何 TP 只用于筛选候选方案。

### 8.3 最小可行解检查

**问：如果 P5 的最优解是一个已有技术，那会是哪个？**
答：三个候选都已有——①每 query 单类（DETR 默认 argmax 解码，260 篇里 119 篇涉及 NMS、0 篇以该短语为题名，说明它不构成独立贡献）；②类内 NMS + 重取预算（标准后处理）；③加大 topk（改一行）。三者**都已在几何层面测过**（5.6(e)、4.33），没有一个同时满足 §8.2 的三条：argmax 过 1、3 未测但 2 的前半条（TP 不减）已否；NMS 过 2 的增幅条款已否；加预算过 1 但违反"检测数仍为 300"。

**结论**：既有技术**没有一条被证明满足规格**，但也**没有一条被证明不能满足**——因为第 3 条（AP）本轮没测。所以 P5 现在的状态是 **"候选，未定级"**，不是 B 候选，也不是 A 素材。判据只差一次冻结协议的 AP 对照。
