3. 支持域与精度
使用本 batch 实际 outputs.ref_points，核等于 pre_outputs.pred_boxes 及所有普通 FDR aux ref_points；不借用 eval 或其他 checkpoint 的 ref。reg_max/up/reg_scale 从 recipe/实际缓存交叉核对，实际 native weighting_function 节点端点给闭域 [a,b]。
主域：把实际 FP32 ref/GT 数值转 FP64，按真实物理解码逆式计算未 clip 四边 d*；四边都在 [a,b] 才 F(q,g)=1。支持外违约 v=sum(max(a-d*,0)+max(d*-b,0))/abs(reg_scale)，只描述，不作为新修复目标。
并列报告原生 FP32 bbox2distance 编码前 raw 四边域、FP64 tight/expanded 域，端点近边 eps=1e-10×max(1,abs(reg_scale))，不据结果改容差。插值审计针对 native 实际 FP32 four_lens。各域图相同时复用证书；不同则以完全相同目标和预算分别求解，报告敏感性。主判定始终 physical64，精度敏感性另列。

4. 固定候选与强控制
逐图逐原正类别作完整整数运输：每个原 q 容量 1，每个原 GT 需求 m_g。E(q,g)=原 owner(q)=g 或 F(q,g)=1。
G_repair：只允许 E，lex(支持外数,改 owner 数,native final matcher cost)。用 E 外边数作最高整数 hardcost，其后上述目标；G0 是零禁止边可行见证，解后核禁止边数为 0。它保证 query 原 inside 不转 outside、changed-still-outside 为 0、每 GT 支持槽不减；这些是算法性质，不是效果证据。
U_cost：无限边 lex(支持外数,nativecost,改 owner 数)。
U_change：无限边 lex(支持外数,改 owner 数,nativecost)。
另报 final_IoU_face=lex(-当前 FP32 IoU 总和,支持外数,改 owner 数)、ref_IoU_face=lex(-初始 ref FP32 IoU 总和,支持外数,改 owner 数)、native_cost_face=lex(nativecost,支持外数,改 owner 数)，以及 G0。无需重跑 193 的 v 优先 G。
完全沿 192：有限 machine float 精确转换 dyadic 有理数，逐层 row-min shift 与可证明总范围构成 Python int 优先级；NetworkX 整数流，独立 exact 运输 dual 逐边不等式及 primal=dual。最后仍并列时按固定插入顺序求解，不冒称 ID 字典序。U_change 的同最优 face 按 exact(支持外数,改 owner 数,nativecost)三元组，不按浮点总和或 owner 是否恰好不同。
