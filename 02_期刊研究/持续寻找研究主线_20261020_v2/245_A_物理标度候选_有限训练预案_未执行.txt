一、原拟回答的问题与三个臂

原拟问题：固定 pre base 框、对同一个 reference 使用完全相同的闭可达域时，F4 对内部物理单位的缩放，是否比只移动端点的 E4 更有利于学习实际边界修正？不是再次证明“范围扩大就能覆盖更多 GT”。

设实际输入 H×W、reference=(cx,cy,w,h)、R=4、原生 33 节点 W_j、端点 W_0=−4/W_32=4，p=softmax(z)、μ=Σp_jW_j。左右 base 边 b_L=cx−w/2、b_R=cx+w/2。三臂均保留原 300 ordinary queries、3 FDR 层、原 GO/own/DN 规则、真实 GT、原损失权重及参数数量。

N：x_L=b_L−w μ_L/R，x_R=b_R+w μ_R/R。
F4：s_x=max(w,4/W)、s_y=max(h,4/H)；只把 residual 中的 w,h 换成 s_x,s_y，base 半宽高不换。水平逆映射分别是 R(b_L−g_L)/s_x、R(g_R−b_R)/s_x。
E4：保留 w/R 解码，两个端点乘 α_x=s_x/w，内部 31 节点不动；纵向同理。等价物理有符号节点的端点 ±s_x，内部为 (w/R)W_j。target 用 E 自己的节点插值，不复用 F 的 target。
N 是任务效用控制；E4 是最强同支持简单控制；F4 是候选。k8、旧全局 T2、pre-size clamp C4 不进入本轮三臂训练预算。

对每一个相同 reference，F4/E4 的四边支持相同，容量/any-query 的闭支持必要界也相同。这是数学自检，不是 F4 的胜项。端到端训练后 reference 会分化，所以不同模型自身的最终支持图未必相同；要声称的是相同支持规则下的内部参数化及反馈，不能偷换成训练全程每个框都拥有完全相同的实际支持图。

二、待证机制要比“L1 梯度小”具体

令一条边的 sign 为 σ，m_tail=p_0+p_32，a_tail=p_32−p_0，μ_inner=Σ_(j=1…31)p_jW_j。相对 N，E4 的新增位移为：
 Δb_E=σ(s−w)a_tail，故 |Δb_E|≤(s−w)m_tail。
F4 的新增位移为：
 Δb_F=σ(s−w)μ/4=σ(s−w)(a_tail+μ_inner/4)。
因此 F4−E4=σ(s−w)μ_inner/4。
E4 扩域增量的 logit Jacobian 为：
 ∂Δb_E/∂z_j=σ(s−w)[p_32(1_(j=32)−p_j)−p_0(1_(j=0)−p_j)]。
其 L1 范数不超过 2(s−w)m_tail。F4 的对应增量为 σ(s−w)p_j(W_j−μ)/4，不必由两端尾质量承载。

可失败假设是：原 PMF 的尾质量很小时，名义上相同的新支持域，对 E4 是否需要更多尾部概率迁移才能产生所需修正；F4 使用内部概率是否有学习上的价值。E4 能重新学习尾概率，因此这个问题不是 E4 永远不可达。上述导数与界限是公式，尚不能证明真实尾概率构成瓶颈；当前 F4 screen 阴性也不能被这段公式抵销。

D-FINE §4.1/附录 A.4 已讨论节点范围、曲率与定位精度取舍。本方案不能主张首次发现“网格影响优化”。另一个强替代解释是局部有效学习率/梯度幅度变化：AdamW 历史二阶矩、全局 clip=.1、FGL 插值、IoU 权重和 LQE 都能改变最终更新，较大 Jacobian 不保证有效参数步更大或更正确。N/E/F 训练即使阳性，首先支持内部参数化的整体作用，不能独立证明纯 Jacobian 因果。
若将来值得进入机制深挖，一个有限的后续简单控制可为 E4 加 detached 的 query/axis 几何梯度增益，检验普通梯度放大能解释多少；它不自动等价 F4，也不加入当前六次短程。不得为排除所有解释扩展无限训练臂。

七、真实尺寸、ordinary/DN、训练/部署必须闭环

实现位置以新副本的 native 为准，历史源不改：
1. DEIM.forward 从实际输入 tensor 的 H/W 获取 input_hw，传入 DFINETransformer。不能用 orig_size、只用 eval_spatial_size=640、由 P3 尺寸猜回输入，或固定4/640。若未来支持动态导出，不得因 Python int/常量折叠把 H/W 烘焙成一次 trace 的值。
2. Decoder 的 pre_bboxes 与 ref_points_initial=pre_bboxes.detach() 保留；F4 只改后续 signed residual 单位。units 从对应初始 ref 与本批 input_hw 计算并 detach；每层共享同 query 的初始单位，不能改为每层新框宽高。
3. E4 要有每 query/每轴的端点网格。可用原 μ 加 4(α−1)(p_32−p_0) 解码，或用等价物理节点期望；须与普通 softmax/Integral 路径的数值契约一致。不能只修改一个全局 project 常量代替 query-specific 控制。
4. 正逆一致：F4 用原 base 的 residual 除 s；E4 按自身节点编码。FGL target 在 no_grad 下生成，IoU、MAL target、DDF matched weight 用实际新框重算，不能固定原零权重。对于负宽高不偷偷排序或 clamp。
5. ordinary、各 aux、DN 各层都携带对应 units/mode；DN split 使用原 offset，DN refs 不能借 ordinary refs；FGL 普通与 DN 缓存各自正确重置。pre/encoder 无 corners 的输出不增加伪 FDR loss。pre 的 GO 几何监督保留，own 仅用于其 MAL。
6. 推理、EMA.module、convert_to_deploy/Integral 的 project cache、独立评估和导出必须使用相同 arm/k/input_hw 规则。arm/k 不必新增可训练参数或持久 tensor key，但必须存入可校验模型身份/config；不能载相同 tensor 后默认走 N。

— state：CPU 只加载两份 CP，strict 检查 raw/EMA模型键形状、488可训练张量对应 optimizer 参数分组/ID、moments/steps、scaler、EMA updates；N/E/F无新增训练参数、三个臂加载后的状态摘要同 seed 完全一致。
— resume：不做 optimizer step 的 CPU dry run 构建训练器，检查 last_epoch=23、output_dir新目录、加载来源副本SHA、下一epoch=24、schedule horizon132、绝对global iteration与各组lr、没有重新warmup；缺失字段 fail closed，不自动填初值。FlatCosine 按第四节解析重建而非要求一个不存在的 state_dict。
— 集成：必要时一小合成 batch（如 B=2、128×192，保证 encoder候选数够300）在 CPU 完整 forward/criterion finite 检查 ordinary+DN，再作同输入 eval/deploy 数值一致性；具体误差容差在实现检查前锁定，N 对原生、F/E对其公式分别核。若只做 pure decoder 测试，必须明确尚未验证全调用链。
— N 必须通过原生数值复现；未来三臂采用实际训练精度时还需记录首真实训练 batch 的 finite loss/grad、正确units和损失路由。CPU检查不伪装成GPU AMP已验证。

这些是工程可运行性，不是额外要求冻结 AP/梯度方向阳性。本精确 F4 版已因229 screen未过而不推进，所以现在不会为它执行上述预检、构建代码或加载 CP。

十一、短训结论在训练前怎么说清楚

本预案的24→36是从原生训练状态切换参数化后的12轮适应性 screen；旧PMF与Adam moments均为 N 学得，F/E 的初始扰动不同。它能排查实施故障、明显不稳定和可重复坏方向，不能代表从头按完整配方训练该参数化的极限，更不能证明低于噪声的微小优效。

不设“必须+.2 pp且显著”之类没有本试验功效依据的硬阈值，也不把两个任意微小正数写成主线成立：
— source/状态/随机输入/输出目录等身份或实现失败：记实施失败，该次不能作方法阴性，按原失败现场保存，不自动改参数重跑。
— 训练有非有限loss/梯度、崩溃或持续非法几何导致原损失不能计算：此版不具备直接训练可用性；停止自身任务并保存，不触碰别的任务、不自动AMP改FP32或重启补预算。
— 六臂完整后，F 相对 N/E 出现两seed一致的任务下降、且不是打印精度/评价器误差，定位和全体代价也支持坏方向：拒绝自动进入完整配方。幅度和所有原始值公开；小幅双负也不冒作普遍显著损害。
— 方向混合、差值很小或缺少一致任务证据：结论为此短程未分清/不支持追加，不能择seed、换best、改k或追训到正为止；不把“未分清”写成严格等效或所有物理标度无用。
— F 相对 E/N 有方向一致且可审查的任务改善，并有对应学习变化：只允许提出进入完整配方的下一次审查；不是自动延长、不是统计显著或已完成论文。
— E/F 都胜 N 而 F 无可重复额外优势：不能宣称内部物理单位是必要的新贡献。若只有 F−E 好、F−N 不好，也不能跳过净效用。

两seed不能估准训练随机方差，548张的配对图像不确定性也不能代替seed方差。若未来报告图像级配对 bootstrap，必须统一三臂重采样并完整重算AP、预先固定次数与随机种子；它不是为达到显著性反复加样/改变终点的工具。本次没有把 bootstrap 实现追加为启动前无限门槛。
