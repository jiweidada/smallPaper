# 360 问题定义与归因 · 提示词 v7（2026-10-26）

上位准则是 C:\Users\jiwei\Desktop\小论文投稿\英文小论文\CLAUDE.md。

v1–v6 都在做同一件事：从已有证据里挑候选、再验一个假设。v5 停在宽度线，v6 想拆覆盖。结果都一样——每轮否掉一个方向，然后没得查。

本轮换根。创新点是"解"，解只能对一个"问题"成立。所以先不找解，先回答：**问题是什么**，它成不成立，它在什么范围内成立，为什么还没有解。

判据不是"这个想法新不新"，而是"它解的是不是一个真问题，而这个真问题现在确实没解"。

---

## 0 四条闸门（任何"问题"必须全过，否则作废）

1. **可测**：有量化现象，有完整协议（数据集、输入尺寸、指标、匹配口径、分母），别人能复现。
2. **可分解**：现象能拆成互斥成因，每份有占比，且能设计反事实或替换实验证明可分离。
3. **有边界**：能说出在什么条件下现象消失或加剧。只在一种设定下成立 → 那是 bug 或数据属性，不是问题。
4. **有未解性**：现有解（文献 + 本项目已试）逐条给"它做了什么、为什么不够"，每条带数或章节号。

过不了任何一条 → 该问题作废。四条全过 → 进 §8 定级。

---

## 1 红线

1. 不许编数据、猜结果、凭感觉估成功率。
2. 不许把"我没查到"写成"本地没有/不存在"。下否定结论前先列目录、报数、贴命令（LIB 递归计数应为 260 = 258 根 + 2 子目录）。
3. 不许把 oracle 上界当提升。
4. 不许用改名充数。
5. 任何"不成立/无效应/未观察到"的结论，必须同时写检出力：这个检验在什么情况下才可能阳性，以及阳性所需量级与目标实际量级差几倍。只报阴性不报检出力，视同编数据。
6. 不许写"小目标本来就难"这类万能句。万能句等于没写问题。

## 3 线程 0：论文现在声称的问题，和证据支持到哪一步

读 main.tex 第 44–57 行与第 84–87 行，把问题陈述逐句摘出，然后回答：

**Q0.1** 论文的问题是关于"信息内容（子格内差异）在 fine→coarse 传递中是否有用"，还是关于"检测在什么条件下失败"？

**Q0.2** 现有证据（C − C-mean 的 APs 差 val 0.449–0.729pp、test-dev 0.163–0.837pp，17,440 参数 0.170%、1.031% FLOPs）回答的是哪一个？

**Q0.3** 如果论文的问题属于"信息有没有用"，它需不需要一个方法创新？还是它本身已经是一篇完整的信息限制实证？

结论必须落成一句明确判定：**论文当前问题 = 实证型 / 方法型**。

这一节可能直接决定后文的走向：若论文是实证型，则 B 路径不能"给现有论文加创新点"，只能"另立一个新问题"。这两种做法在写作上是两篇不同的论文，不许混着来。

## 5 线程 2：机制分解（本轮主体）

### 5.1 必做判别一：Geo0 的框形（零成本，L1，先做这个）

用现有 GT + 342 缓存，算 Geo0 的宽高比分布：w/h 的中位与四分位，**原始分辨率与 640 拉伸后各一套**。

判别：若 Geo0 多为窄高条（w ≪ h），则"横向定位难"是目标形状属性；若 w ≈ h，则各向异性拉伸才是成因。

必须报：原始分辨率下 Geo0 的 w 像素数（中位 / p10 / p90）、w<4px 与 w<8px 的占比；h 同样一套。

这一步不先做，后面所有"横向"结论都站不住。而且它决定 §7 的问题陈述能不能写"各向异性"四个字。

### 5.2 必做判别二：无近邻样本是"没框"还是"框在远处"

对口径②未覆盖的约 2472 / 2380 个 Geo0，找最近的同类预测，报：

- 距离（中心距）分位数：p25 / p50 / p75 / p90
- 该预测是否在图像边界内
- 该预测的分类分数分位数

判别：距离 ≤16px 但分数被砍 = 排序问题；距离 >32px = 根本不是这个目标的框，属覆盖问题。两种成因对应的方法方向完全不同，必须分开报占比。

### 5.3 三分解（沿用 v6 线程 C）

对每个 Geo0 取中心 r = 8 / 16 / 32px 窗口：窗口内 query 数、最高分类分数、该 query 的 IoU、是否过后处理阈值。

- A 无 query：窗口内 query 数 = 0
- B 有 query 但分数低于阈值
- C 有 query 且分数够但 IoU<0.5

三情形占比，两 seed 分开。某一情形 ≥70% 才算主导，否则记 mixed，不许硬挑。

### 5.4 反事实替换（仅当 C 主导时做）

把匹配框的 w / cx / cy 分别替换为 GT 值，再全替换，报 IoU≥0.5 的救回数与占比。这一步决定"位置"还是"尺寸"是主因。

### 5.5 机制命题

用一句可判定的话写，形如：

> 在条件 X 下，Geo0 的失败主要由 Z 造成，占 p（分母 n）；证伪它的观测是 Y。

必须能写出"证伪它的观测"。写不出来，说明这个命题不可判定，退回重写。

## 6 线程 3：边界（问题在什么范围内成立）

至少三维，每维报"现象是否复现 + 量级"：

1. **输入形状**：640×640 拉伸 vs 832×480 保比。直接复用 349/350 的已测数，不许重跑。
2. **尺度**：Geo0 只是 tiny 的子集。small 与 medium 上同一现象是否存在？（用 342 缓存，L1）
3. **数据集/类别**：UAVDT 全是车。若 VisDrone 上同类现象占比相近，则不是车辆属性；若差异大，问题要加"车辆/长宽比"这个边界条件。

这一节的产出是一张"成立范围"表。现象只在 tiny 上出现，恰好说明问题在 tiny 定位，而不在通用检测——这是好事，不是坏事，要写清楚。

## 8 线程 5：问题陈述与规格

### 8.1 问题陈述（1–3 条）

每条必须含四成分：条件（何时）/ 失败（什么错、多少）/ 成因（占比）/ 未解（谁试过、为什么不够）。每条 ≤60 字，且不许出现"小目标""难"这类无信息词。

### 8.2 由问题推规格

每个问题写 3 条以内的"解必须满足"，每条能转成验收判据：在哪个数上、达到多少算支持、多少算否掉。

### 8.3 最小可行解检查（防自欺，本节不许跳过）

对每个问题问一句：**如果最优解是一个已有技术，那会是哪个？**

- 答案是某个已有技术 → 这个问题不是方法问题，划到 A 路径，别硬做方法。
- 答案是"没有已有技术能同时满足三条规格" → 才允许进 B 路径。

356 的结论之所以是"零训练筛选产生不了新方法"，就是因为从没做过这一问：一直在权重上找异常，从没检查"异常对应的解是不是早就有了"。

## 9 线程 6：定级与去向

一表：问题 / 四闸门（过·不过 + 证据）/ 类型（A 实证 / B 方法）/ 若 B，可区分点一句话 / 最近邻先例（文件 + 章节）。

- 四闸门全过 + 最小可行解不是已有技术 → B 候选

- 任一闸门不过 → 作废，写清卡在哪条
