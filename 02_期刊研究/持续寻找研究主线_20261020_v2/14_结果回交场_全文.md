**具体设计与独立依据**

在冻结源码的`corners`累计、`distance2bbox`之间改接分布状态。第ℓ层以 \(a_\ell=\mathrm{sg}(b_{\ell-1})\) 生成每边的新物理网格 \(x_{\ell j}\)。将旧概率按物理位置拆分到相邻新bin；越界质量分别存入两个尾部槽，其坐标取该尾部的条件均值。记结果为 \(Tp\)：它保质量、保均值，但不保尾部内部形状，不能称无损迁移。

为让新位置获得概率，构造新网格上均值等于旧预测边位置的最大熵分布 \(u\)，固定：

\[
q=0.9Tp+0.1u,\qquad
p_\ell=\operatorname{normalize}(q\exp r_\ell),\quad
b_\ell=\sum_jp_{\ell j}x_{\ell j}.
\]

因此零残差时框不跳动，新bin又有非零概率。只有参考框detach；概率和尾部一阶矩保留梯度，使后层几何损失继续作用于前层分布。需验证旧边位置处于新网格内部，否则上述构造不成立。

## 对 Codex A 的回应

**1. 与 D-FINE 的实质区别比原表述窄。** 冻结源码中，corners 本来就是逐层累加 logits 后再做 softmax，相当于已经在用 normalize(p_prev·exp r)，只是网格固定在初始框上。因此，0.9Tp+0.1u 再乘以 exp r，与 D-FINE 唯一真正的差别是重新划分网格的映射 T，以及那 10% 的平滑先验。“保留物理概率历史”本身不是新东西。可主张的增量只能是：在支持域移动时，仍然保留 logit 累计的语义。

**2. 与“范围×2失败”的界线需要明确写出。** 移动网格的总可达距离大约是层数乘以单层范围，本质上是一种条件式扩大范围：只有前层把框推向边界时，后层才能走得更远。它和统一×2的区别仅在于这个条件。如果失败配对的末前层框并没有朝 GT 方向贴边，那么移动网格只是把错误方向的框重新居中，不会产生新的可达配对。

**3. A5 的触发本身有一个反例风险。** 零 IoU 时 FGL 权重为 0，不论网格怎么移动都一样。所以能把框带出原范围的只有 L1/GIoU 的梯度。候选实际检验的命题应当是“L1/GIoU 已经在推，但被支持域截断”，而不是“FGL 不可达”。此外，A5 中有 526/543 个配对可由别的 query 到达，这涉及匹配身份，移动网格并不处理它。

**具体修订：取消动态尾槽，采用固定33节点的包络迁移。**

触发仍是材料A5的551/680次“全部query均不可达”曝光，不将其解释为训练因果。A、B的尾槽条件均值会让节点本身依赖旧概率，增加梯度与FGL编码的复杂性。可以在第二层令参考为 \(\mathrm{sg}(b_1)\)，生成局部33节点 \(g_0,\ldots,g_{32}\)，再定义：

\[
X'=\{\min(x_0,g_0),g_1,\ldots,g_{31},
       \max(x_{32},g_{32})\}.
\]

这里 \(x\) 是该边原物理节点；所有节点坐标停止梯度，此后不再移动。旧节点全部位于新包络内，故相邻插值矩阵可满足

\[
\mathbf1^\top T=\mathbf1^\top,\qquad X'^\top T=x^\top.
\]

沿用 \(q=.9Tp+.1u,\ p_2\propto q e^{r_2}\)，其中 \(u\) 是新网格上均值等于旧均值 \(m=x^\top p\) 的最大熵分布。**\(m\)不能detach**：零残差时不仅要求框值相同，还要求对旧概率的几何导数相同。否则所谓“保留历史梯度”并未成立。

接入点仍是第二层`corners`累计与`distance2bbox`之间；后续在新网格累计logits，FGL使用排序节点的相邻插值。33个节点均接收残差，无新增尾槽。这保质量、保均值，不保完整形状；远端节点也可能牺牲局部分辨率，属于待检验代价。

**强对照与证据边界。**

同网格的 \(u\) 重置必须同样保均值及上述导数；Claude的“清零logits”通常产生均匀分布、改变初始框，不能单独隔离历史价值。另保留零初始化的四维直接残差，以及固定坐标关闭DDF的基线；机制比较臂统一关闭DDF。

据共同材料，D-FINE已有分布累计，DINO已有迭代参考框，LD已有分布蒸馏；我未自行核读原文。剩余贡献只能是跨坐标继承概率优于同坐标重置，包络构造本身不足以立项。DINO的梯度处理仍需原文核对。

最低成本核查是用缓存首层框构造这个确定网格，检查新增可达曝光，并用合成概率验证质量、均值、零残差导数及框合法性。它只检验构造与冻结落点，不预测训练轨迹，也不能区分共享支持域的迁移和重置。若没有新增可达曝光，撤回本版的越界救援依据；若训练收益被重置或直接残差解释，撤回分布历史贡献。我的未决点是历史是否有用，而不是要求缓存先证明最终AP。

一、候选与最近原文的具体对照

候选一：累计分布残差上的逐层几何约束蒸馏。
真实触发：旧同前向 D5 中，教师更差配对约占 raw student-IoU 正权重和的43%，其中约75%的输出坐标蒸馏梯度与几何梯度相反。这不是网络更新损害证明。
干预：在普通正项 DDF 可达的新增 corner 残差 r0/r1 上汇总梯度，逐 query 求保护 aux0/aux1/final 原 union 几何梯度的最近半空间交集投影。负项、DN、其余损失和推理不变。

最强简单对照：同坐标单总损失投影、逐 query 等范数缩放，另含半权/关闭正项和教师更好门控。

### 独立路线：用边界两侧的特征差形成初始框

我提出一个候选：**在固定FDR参考生成之前，让初始框直接读取边界内外的浅层特征差。** C相对baseline的APs已有+0.837/+0.669pp，支持继续研究特征路径，但尚未证明收益来自边界信息。

具体在首层`pre_bbox_head`输出与`ref_points_initial`之间接入。以原预测框的停止梯度副本\(a\)确定四条边；每边取等面积、镜像相邻的内外条带，宽度固定为浅层特征步长的一半。定义：

\[
d_e=\operatorname{Avg}(F,S_e^{in}(a))
-\operatorname{Avg}(F,S_e^{out}(a)),\qquad
u'=u+W[d_L;d_T;d_R;d_B].
\]

\(u\)为原框的sigmoid前四维输出，\(W\)零初始化；新`pre_bboxes=sigmoid(u')`随后生成原生固定参考。条带坐标detach，梯度经\(W\)、采样特征返回浅层骨干。原pre几何监督仍可训练这条路径，无须等待IoU加权FGL激活。

它改变的是**初始框获得什么图像证据**，因此可能改变原本全部query不可达的1170/895次曝光所对应的初始支持；不是在错误初始框上搬运概率。待证假设是这些候选附近仍有可读取的边界对比；远离目标的框可能完全受益不了。

## 我的主候选：对未入选 encoder 位点做纯几何的中心位点监督

**真实触发。** 07 中有 1170/895 次曝光对全部 300 个 query 都不可达，问题在 decoder 之前。A4 的 GT 辅助上界显示，短边 <4 的 GT 每个 seed 329 个，在 IoU.5 下 TopK 覆盖 92/82，全有效池覆盖 107/102，即约三分之二在整个 dense 池里都没有合格框。A3 也显示，短边 <4 的漏检中 96% 在三个阶段从未被覆盖。

**可证伪假设。** encoder 框头只在 topk 选中的位点接受几何监督（A4 已注明未选 token 不受同等监督）。tiny GT 的中心位点长期不被选中，因此回归能力欠训练。

**干预公式。** 在 `_get_decoder_input` 中，topk gather 之前取 dense 输出：

`enc_coord = enc_bbox_head(output_memory) + anchors`

对每个 GT g，取最细层包含其中心的位点 s(g)，增加损失：

L_cs = Σ_g [5·L1 + 2·GIoU](σ(enc_coord[s(g)]), g) / N

这一项只作用于几何，不加分类项。因此 topk 选择、MAL 与匹配都不直接变化，推理零成本。多个 GT 共用一个位点时，取中心最近者，冲突数单独登记。上述变量名按开源 D-FINE 结构书写，冻结版需要核对。

**与近邻的实际操作差别。**
- RT-DETRv3（P09）另加 CNN 一对多辅助头，监督分类和框。本候选不加分支，直接监督原 enc 头在未选位点上的回归，且不加分类。
- DEIM 的 Dense O2O 增加每图目标数，但监督仍限于 topk 匹配。
- ATSS 类密集分配同时训练分类，我未读其原文细节。

**最强简单替代。** 同位点同时加分类和框（标准一对多），以及直接把 encoder topk 增大。若纯几何版不胜过这两者，就撤回“只补几何”的主张。

**最低成本、有判别力的无训练核查。** 使用 A4 已有的 dense encoder 框包，短边 <4 的 GT 按 seed 分组。在中心位点上，比较“该位点被选入 topk”与“未入选”两类的 encoder 框 IoU。为控制选择本身与特征质量的混杂，按类别分数分档后再比较。

- 若同分档下未入选位点的 IoU 不低于入选位点，说明监督缺口不是主因，失败更可能在特征形成，本候选放弃。
- 只有两个 seed 都出现一致的入选优势，才值得申请训练验证。
