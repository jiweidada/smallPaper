三、对论文的含义（2026-10-26 按用户意见收窄）
- 第二数据集的支持证据：C−C-mean 在两个 seed、两个划分上全部为正，test 上为 +0.745/+1.031。这与 VisDrone 的 3 个 seed 方向一致，可以作为子格差异增量收益的跨数据集支持。
- 相对基线：受测的 C 和 C-mean 在 UAVDT test 上都低于基线（C−baseline −1.969/−0.826，C-mean−baseline −2.715/−1.857）。这个结论只限于这两个受测实现，不推广成"P2 融合在 UAVDT 上有害"。
- 写法：子格差异相对均值的增量收益在第二数据集上复现；受测实现相对基线的净收益依数据集而变，在 UAVDT test 上为负。不写"C 在两个数据集上都有效"。
- val 与 test 差距很大（基线 84.5 对 56.5）。UAVDT 的 test 是作者给定的测试序列，val 是训练序列中留出的部分，场景分布不同。稿件里要交代这一点，不能只报 val。
- 只有 2 个 seed，不做显著性表述。
