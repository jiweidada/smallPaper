Abstract
Detecting objects from UA V-captured images is challenging due to the small object size. In this work, a simple
and efficient adaptive zoom-in framework is explored for object detection on UA V images. The main motivation is
that the foreground objects are generally smaller and sparser than those in common scene images, which hinders the
optimization of effective object detectors. We thus aim to zoom in adaptively on the objects to better capture object
features for the detection task. To achieve the goal, two core designs are required: i) How to conduct non-uniform
zooming on each image efficiently? ii) How to enable object detection training and inference with the zoomed image
space? Correspondingly, a lightweight offset prediction scheme coupled with a novel box-based zooming objective
is introduced to learn non-uniform zooming on the input image. Based on the learned zooming transformation,
a corner-aligned bounding box transformation method is proposed. The method warps the ground-truth bounding
boxes to the zoomed space to learn object detection, and warps the predicted bounding boxes back to the original
space during inference. We conduct extensive experiments on three representative UA V object detection datasets,
including VisDrone, UA VDT, and SeaDronesSee. The proposed ZoomDet is architecture-independent and can be
applied to an arbitrary object detection architecture. Remarkably, on the SeaDronesSee dataset, ZoomDet offers more
than 8.4 absolute gain of mAP with a Faster R-CNN model, with only about 3 ms additional latency. The code is
available athttps://github.com/twangnh/zoomdet_code.
