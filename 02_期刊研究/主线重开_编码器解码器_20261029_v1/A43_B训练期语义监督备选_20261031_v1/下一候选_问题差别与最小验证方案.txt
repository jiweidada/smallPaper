1. 直接建议与界限

A42 的“定位专用读出”未过固定投入门槛，停止该主张，不继续扫层数、采样范围或损失权重。共享读出组的收益保留为控制结果，不自动改写成另一篇论文的已成立创新。
下一候选暂定 A43-B：用已有紧凑检测器的实例 query，监督早期空间特征的训练期语义适配。
研究问题：对 VisDrone + ECDet-S，在同一冻结教师、同一目标实例、同一学生投影器和同一损失形式下，直接对齐最终匹配 query 的实例表征，能否比对齐同一教师的区域特征，更有效地改善小目标检测？
这个候选属于编码器表征学习的改进设想，尚不是一种已实现的新 encoder/decoder 架构。

项目事实：A42 单 seed、12 轮结果不支持定位专用优于共享；它没有测出“浅层语义不足”这一机制。历史 A39 使用不同的 CNN 宿主，局部特征与 query 判别差异的区间跨零，也不能用作 ECDet 语义缺陷已经成立的证据。
文献推断：已有检测蒸馏工作说明，知识选择和实例条件值得研究；紧凑 ViT 的任务表征学习可能重要。它们不保证下面的直接 query 目标在航拍小目标上有效。
待验证假设：匹配 query 聚合的实例上下文，可能比混有邻近背景的区域均值，提供更合适的早期表征监督；也可能因教师误检、实例混合或表征不兼容而更差。

4. 拟定单一算法改动

学生：原版 ECDet-S；不保留 A42 推理读出分支。
教师：已有 A42 原版 B 固定第 12 轮 EMA 检查点，完全冻结。它是一个短训教师，不假定它对所有小目标都正确，也不新训练大型教师。
训练期在同一张增强后的输入上获得教师的最终 query 和已有 stride-16 区域特征。用教师原生最终 Hungarian 匹配确定 query—GT 对应；仅使用真实检测 query，去噪 query 不混入。M/Q 两组用同一个教师和相同实例集合。
学生使用现成 stride-4 stem，按对应 GT 区域取 3×3 RoIAlign、平均后经过同一 48→192 线性投影和 L2 归一化。教师向量停止梯度；不另加关系损失、困难样本门控、负样本挖掘或新 decoder。
M 控制：目标为同一教师对应区域的 stride-16 特征向量；Q 候选：目标为同一 GT 对应的最终 192 维 query 表征。教师目标均归一化，两组均用实例平均的 1-cosine，暂定固定权重 1。
Q/M 的差别限定为监督目标的来源，不以两个不同大教师或额外损失堆叠来混淆比较。投影器训练后移除；推理模型结构恢复原版。
GT 只用于训练监督，验证/推理不使用 GT 读出。这些是设计约束，当前尚未实现或通过接口验收。

5. 可承担的最小判别方案草案

组别：fresh B 原版、M 区域特征蒸馏、Q 直接实例 query 目标。A42 B 只作冻结教师与历史结果，正式新比较保留 fresh B，避免不同配方/时段混比。
数据：VisDrone DET 官方 6471/548 划分；保持 A42 的类别、忽略区、原图小目标面积、maxDet300 和 COCO-style 口径。
共同初始化：A42 已保存的同 SHA 十类 COCO 初始化，不能从 A42 的已训学生接着训练。M/Q 投影器相同初始化。
草案 seed=20261101；单卡顺序，每组最多 12 轮；640 输入；有效 batch8；相同优化器、EMA 和固定第12轮。不得按中间结果改权重或阶段。实际执行前一次冻结全部细节、停止条件及源码。
教师匹配与目标按同一输入生成；优先在线 frozen no-grad 小型教师，若容量不合格就停止该实施，不追加一套缓存/裁图搜索来绕过。两组教师路径完全相同，计算单独计数。
主指标改为 APs，因为这是独立的新监督问题；不是把 A42 的 AP75 门槛改低后继续使用旧结果。小目标 AP75 与总 AP 同时报告。
拟定投入门槛：Q-B APs≥0.5pp、Q-M APs≥0.3pp，总 AP≥B-0.2pp。部署图应与原版同构；仍需实测延时，不能凭移除辅助模块直接宣称更快。
最低接口验收：教师无梯度、M/Q 使用相同 teacher/实例/输入，投影器有有限梯度，删除辅助模块后可严格导出原版推理状态。一次真实密集 batch 容量验收；建议保留约22GiB上界。失败即停止排查，不自动降低门槛、加教师或加新损失。
若 Q 只优于 B 而未优于 M，停止“直接 query 目标有独特价值”的主张。若三组短测无有用差别，换问题，不连续扫蒸馏权重/层数。通过只表示值得下一阶段，仍需重复、充分训练及最近方法比较。
本草案没有执行分配；不得自动启动。

6. 可行性与主要风险

已有资源事实：A42 原版训练峰值约12.75GiB，12轮约62.5分钟；本机连接的24GiB RTX3090可完成原版迁移短测。新的在线教师会占额外显存/耗时，当前没有该配置的实测，不能把旧容量直接当作新容量通过。
工程推断：教师与学生均小模型，且教师不反传，三组12轮应属于现有资源可考虑的范围；这需要实际容量验收，非已证明可行。
算法风险：短训教师未必提供强知识；query 与局部特征可能不在兼容空间；投影器可能吸收全部匹配而未改变 stem；对小于一个粗 token 或拥挤目标的匹配覆盖不足；已有蒸馏方法可能已覆盖直接目标思想。
检索风险：TSC-DETR 方法仍未按可核验出版社/作者正文核实，不能声称已排除它。它不阻止写出受控候选，但足以限制新颖性措辞。
统计风险：单 seed、同一公开验证集和此前多次选题使后续仍属探索性；门槛不是显著性检验。

决策：保留为一个具体的下一候选和可承担判别草案。此时不称研究主线已获效果验证，不保证能支撑期刊论文；本轮交付到该方案为止。
