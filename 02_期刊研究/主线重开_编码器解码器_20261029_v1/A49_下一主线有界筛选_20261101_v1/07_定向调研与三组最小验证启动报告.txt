A49 定向调研与三组最小验证启动报告
当前裁决：值得完成这一次有上限的对照，但尚未确认论文主线。
数据：VisDrone2019-DET。算法宿主：ECDet-S。候选增量：已知忽略区域与 decoder query 读取范围绑定的训练监督规则。
这不是已经验证的新 encoder，也不把普通忽略区处理包装成创新。

1. 研究问题及证据等级

【本次数据/源码事实】当前接入保留了 VisDrone class0 忽略矩形，但训练 target 未携带这些矩形。原生 MAL 对未匹配普通 query 施加负类监督，所核查的分类函数没有空间忽略区输入。
这只描述当前数据接入与宿主的组合，不推广成所有 DETR 的缺陷。

完整统计核对训练6471张、验证548张标注SHA，并重算有效GT。训练含343204个有效GT，2648张图含8811个有效忽略矩形；平均每图忽略并集面积占0.342104%，按总像素加权占0.333616%。验证为38759个原始有效GT、340张图含1378个忽略矩形，平均占1.067446%。训练原始8813条class0记录中的2条裁剪后无正面积。
这证明显式忽略区域存在；面积占比不能换算成漏标目标数、错误负例比例或漏检原因。

【推断】一部分普通 query 的背景监督可能来自数据明确要求忽略的内容。因此普通框重叠忽略值得作为强简单对照。
【待验证假设】query 的实际 deformable 读取范围可能比其预测框更贴近该次分类所使用的空间内容，由此提供额外收益。
【主要反例】读取上下文不等于输出对象来自该区域。读取质量不是未标注目标概率或因果贡献。忽略区总体面积较小，收益可能很弱，也可能因放过合法背景而增加误检。

3. 核心文献矩阵与最近工作对比

SparseDet，ICCV2023：
【原文方法】两种视图共用RPN proposal，通过objectness和GT-IoU挖掘潜在未标注前景，再做区域一致性学习。
【阅读范围】选定§3.1—3.5；出版社PDF第4页图2、式1—5已视觉核对，未完整阅读实验。
【对比推断】伪正例挖掘、保护潜在前景与一致性均已有先例。本候选不挖正例，使用数据直接提供的class0空间场；所读方法没有这一读取范围门控。不能由此断言全球没有类似方法。

BRL，arXiv:2002.05274v1：
【原文方法】根据负类置信度及混淆区域改变Focal负分支，包含镜像正分支，并非仅删除负样本。
【阅读范围】选定§4及关联实验语境；PDF第2—3页图2和式1—2已视觉核对。未将预印本读取等同最终出版版全文。
【对比推断】修正缺标情形下的背景梯度早已有之。本候选依赖已知空间区域，不把高置信预测改成伪正例；普通负例抑制不能作为新贡献。

PUD-DETR，公开软件：
【源码事实】kjh0902/pud_detr固定f3ab22816574c8f41107ab9eca66b74483c2cd9a，核查README及train_pud_detr.py 536—724行。选定代码把零one-hot的query—class位置视作未标注风险，进行正例风险校正和非负约束；所读函数无空间忽略场/读取范围输入。
【范围限制】README的论文链接和发表信息待补，按软件先例记录，未核验正式论文或复现性能。AISLAB旧仓库只读README，代码已获取但未方法阅读，不混合两版作者/结果。
【对比推断】通用PU分类风险不是候选创新。本候选仅对全未匹配普通query移除特定负监督，保留匹配query整行分类监督，并以明确空间标注为条件。

Gated DeltaNet-2 v1 / Deep Delta Learning v3：
【原文摘要】分别涉及内容擦写门控、按深度读取比较与重写；这里仅阅读原始摘要，PDF已归档。
【裁决】保留为架构灵感，没有选定UAV特有操作和即用宿主，未启动迁移训练。DDL已知有v4，未把读取的v3称为最新版。这不否定整个Delta视觉研究方向。

4. 有文献依据、但尚未证明成立的研究空白

已核查的工作支持“背景监督在缺标/稀疏标注下需要处理”，但不能据此认定新的问题发现。
较窄的待研究问题是：对已知空间忽略区域，DETR式分类监督的有效性判断，能否从预测框覆盖率改为实际 query 采样支持，并在普通覆盖规则之上获得稳定的小目标收益？
这是有限检索范围内尚未解决的对照问题；尚不是“无人做过”的创新声明。若M足以解决或Q无额外收益，本候选不构成值得继续的主线。

候选可描述为“已知忽略场条件下的query负监督有效性规则”。是否具有足够算法增量，取决于它对普通框覆盖控制的额外贡献及后续最近工作核查。普通忽略区处理、负例重加权、PU风险本身不计为创新。

6. 已冻结的最小验证

宿主：EdgeCrafter固定d8752b75c9beaecfcdd0e5cd207bae3b6946ae23的ECDet-S，三组各9803112参数、原生BN。
数据：VisDrone train6471/val548、10类。统一640×640拉伸、ImageNet归一化、确定性翻转，无Mosaic。
B：原版MAL，忽略区仅用于统一评估。
M：仅对全未匹配普通query，当忽略矩形并集占裁剪预测框的比例IoF≥0.5时，省略该行负类损失。
Q：decoder使用脱离梯度的平均头原生采样质量，读取每个特征单元被忽略并集覆盖的面积分数；质量≥0.5时省略该行负损失。无deformable读取的pre/encoder输出回退到M。
所有匹配query的整行分类监督保留，DN、匹配和框/定位损失不改。Q额外读取仅训练使用，推理恢复原生采样核，不输入GT或忽略场。

同初始化、seed20261101、batch8、809步/轮，各12轮/9708次更新；同AdamW、500步warmup及余弦日程、BF16前向/FP32损失、同EMA。
第4/8/12轮评估；固定第12轮EMA裁决，不选最佳轮次。
统一评估为maxDets300、原图裁剪GT面积定义的小目标及class0并集过滤的COCO式指标；不是官方VisDrone分数，不能与官方榜单直接比较。
全部执行细节、12个文件SHA见protocol_FROZEN.json，其SHA：

三项门槛必须同时满足：
Q−B APs≥+0.5个百分点；
Q−M APs≥+0.3个百分点；

这些是投入判别门槛，不是统计显著性、创新或论文成立的证明。
