Abstract
Few-shot object detection aims to detect novel classes with
limited samples. Recent methods have leveraged rich seman-
tic representations of pretrained vision transformer (ViT) to
overcome limitations of model fine-tuning, thereby improv-
ing performance on novel classes. However, existing pre-
trained ViT schemes only perform transformer encoding in
feature dimension, ignoring exploration of pixel-wise differ-
ences in low-level features and multiscale variations. The
current challenges lie in: (i) extracted features suffer from
blurred boundary features and smooth transition from cen-
ter to boundary, leading to insufficient distinction between
objects and backgrounds, and (ii) how to balance extraction
of local details and global contour features under multi-
scale scenarios. So Pixel Difference Vision Transformer
(PiDiViT) is proposed. Innovations include: (i) difference
convolution fusion module (DCFM), which enhances fea-
ture differences from object centers to boundaries and ef-
fectively preserves global information by fusing pixel-wise
central difference features with original features through
an attention mechanism, and (ii) multiscale feature fusion
module (MFFM), which adaptively fuses features extracted
by five different scale convolutional kernels using a scale
attention mechanism to generate attention weights, achiev-
ing an optimal balance between local detail and global se-
mantic information extraction. PiDiViT achieves SOTA on
the COCO benchmark: surpassing few-shot detection SOTA
by 2.7 nAP50 (10-shot) and 4.0 nAP50 (30-shot) for novel
classes, exceeding one-shot detection SOTA by 4.4 nAP50
and open-vocabulary detection SOTA by 3.7 nAP50. The
code is available at https://github.com/Seaz9/PiDiViT.

The contributions are summarized as follows:
• We propose PiDiViT, which empowers pretrained ViT
to excel in few-shot detection by designing explicit prior
modules for pixel-wise differences and multiscale vari-

• We design DCFM to enhance feature differences of

reference for future detecting few-shot objects.
2. Related Work
Few-Shot Object Detection (FSOD) aims to detect novel
classes with limited samples [18]. Existing methods
can be categorized into two groups: fine-tuning methods
[6, 9, 20, 39, 40, 43] and meta-learning methods [5, 15, 44].
Fine-tuning methods adapt pretrained features to novel
classes through model fine-tuning, but suffer from com-
plex training processes and performance gaps between novel
and base classes due to insufficient fine-tuning with limited
novel data [50]. Subsequently, metalearning methods with
online adaptation capabilities have gradually become main-
stream, overcoming the complexity of model fine-tuning.
These methods have evolved from early prototype-based fea-
ture matching techniques [15, 44] to more advanced dense
support-query feature interaction mechanisms [10–12]. Re-
cently, DE-ViT [49] proposed a solution that replaces train-
ing prototype classifiers with projection of ViT features into
subspaces, effectively avoiding base class overfitting and
model fine-tuning. However, current ViT-based methods
struggle to address performance gaps caused by oversmooth
features from center to boundary and multiscale size fea-
ture discrepancies. Our PiDiViT effectively bridges these
gaps through DCFM and MFFM modules, achieving differ-
ential enhancement of smooth center-to-boundary features
while preserving global features and adaptively capturing
multiscale local details and global contours.
One-shot object detection (OSOD) extends FSOD to
the more challenging scenario of detecting novel categories
with a single support sample, without requiring fine-tuning
[45]. Early approaches focused on improving the interaction
between support and target features [14, 21, 27], but were
limited by the scarcity of support samples and the com-
putational overhead associated with inference per category
[4, 50]. Recent advances, such as DE-ViT [49], have im-
proved efficiency by leveraging the characteristics of a dot
product to match the features. For feature matching, the pro-
posed PiDiViT employs cosine similarity instead of the dot
product to project features into feature subspaces. The pro-
posed DCFM module achieves differential enhancement of
smooth center-to-boundary features while preserving global
information, while the MFFM adaptively balances local and
global features across multiple scales. This combination of
explicit prior modules yields remarkable results even under
the extreme constraints of OSOD tasks.
Open-Vocabulary Object Detection (OVD) aims to de-
tect objects of unknown categories using category names
or textual descriptions [46, 48]. Recent advances in vi-
sion language models, particularly CLIP [30], have signif-
icantly propelled the field forward by enabling the train-
ing of transferable visual models through text. Cooperative
foundational models [2] have shown exceptional results by
leveraging complementary strengths of CLIP and SAM to
transform closed-set detectors into open-set detectors. Re-
cently, pretrained ViT architectures have shown remarkable
potential in open-vocabulary scenarios. For example, DE-
ViT [49] achieved impressive performance in both FSOD
and OVD tasks by replacing the prototype classifier training
with the projection of ViT features into subspaces. Despite
the advancements made by pretrained ViTs, current ViT-
based approaches only perform transformations and encod-
ing in the feature dimension, overlooking the exploration of
pixel-level feature disparities and multiscale variability. The
proposed PiDiViT addresses this limitation through explicit
prior modules such as DCFM and MFFM, which specifi-

3. Method
3.1. Method Overview
Model Background. The proposed Pixel Difference Vision
Transformer (PiDiViT) builds upon DE-ViT [49], which in-
tegrates pretrained Dinov2 ViT [29] into the Meta RCNN
[44] framework. DE-ViT [49] refines and propagates ini-
tial proposal regions and input features through the Region
Proposal Network (RPN) [32] to achieve object localization.
Compared to DE-ViT [49], the innovation of our PiDiViT
model lies in the DCFM and MFFM modules.
As shown in Fig. 2 (a), PiDiViT (Fig. 2 (a)) follows a
bottom-up processing pipeline: the model takes initial re-
gion proposals, category prototypes and ViT features as in-
puts. First, initial region proposals are generated by a class-
agnostic Region Proposal Network (RPN) [32], and category
prototypes and ViT features are projected into input features
via a Cosine Similarity Projection Subspace (CSPS∗, brown
cuboid in Fig. 2(a)). Second, the initial proposal regions are
scaled into masked regions (yellow bounding box areas in
Fig. 2 (a)), and then the masked regions and input features
are processed by a three-layer difference multiscale fusion
layer (dashed box in Fig. 2(a)). These layers include the
proposed difference convolution fusion module (DCFM)
(Fig. 2 (b), green) and the multiscale feature fusion module
(MFFM) (Fig. 2 (c), blue). DCFM enhances smooth feature
differences from center to boundary, while MFFM extracts
global and local information at different scales. The input
region and the middle output region are combined through
concatenated residual summation across these layers to ob-
tain the final input region, which is then fed into the last
layer for processing to generate the final output region. The
input features are progressively refined through three lay-
ers to yield the output features. The final output includes

3.2. Difference Convolution Fusion Module DCFM
Existing few-shot object detection methods such as DE-ViT
[49] adopt a pretrained ViT scheme that performs transfor-
mational encoding only in the feature dimension, overlook-
ing the exploration of low-level feature discrepancy. The
features extracted by DE-ViT [49] exhibit conditions such
as blurred boundary features and excessively smooth tran-
sitions from the center to the boundary, resulting in a less
effective discrimination between target and background fea-
tures. In particular, feature discrepancy is a critical means to
distinguish target features under the scarcity of labeled sam-
ples in few-shot scenarios. It has recently been shown that
pixel difference convolution (PDC) [35–37] can be highly
discriminative while being extremely efficient to compute,
yet flexibly integrated into convolutional neural networks.
However, they have rarely been integrated with ViTs. Build-
ing on these advances, we propose a novel difference con-
volution fusion module (DCFM) designed to explicitly in-
tegrate higher-order local differential features with standard
convolutional features.
As shown in Fig. 2 (b) (green), DCFM adaptively fuses
Central PDC (CPDC) [35] and standard convolution via an
attention mechanism: the CPDC enhances the smooth fea-
ture discrepancy from the center to the edge by highlighting
spatial positional value changes, sharpening target edges
in features to better differentiate targets from backgrounds.
This is then fused with the global information extracted by
standard convolution, enabling the model to accurately rec-
ognize boundary pixel difference variations while retaining
ability to extract global object representation information.
In [35, 36], the authors designed three types of PDC
(Central PDC (CPDC), Angular PDC (APDC) and Radial
PDC (RPDC)) for probing higher-order local differential
features inspired by the famous Loal Binary Pattern meth-
ods [23, 28, 34]: (i) CPDC follows CD-LBP to capture
center-neighbor differences, (ii) APDC models circumfer-
ential variations based on AD-LBP, and (iii) RPDC extracts
radial gradient information inspired by RD-LBP. As shown
in Fig. 3, these PDC variants [35] establish a multiperspec-
tive structural representation through different sampling and
differential computation strategies. The key difference be-
tween PDC and standard convolution lies in that PDC incor-
porates pixel differential calculations into the convolution
operation. The computational processes of standard convo-
lution and PDC are shown in Eq. (1) and Eq. (2).

3.3. Multiscale Feature Fusion Module MFFM
Existing few-shot methods, such as DE-ViT [49] refine pro-
posal regions by stacking single-scale propagation layers,
achieving promising results in few-shot detection. However,
their fixed single-scale structure lacks an adaptive mech-
anism to balance and fuse local-global features extracted
at different scales, limiting robustness in detecting objects
of varying sizes and impairing performance balance and en-
hancement between base and novel classes detection. To ad-
dress this, we propose the multiscale feature fusion module
(MFFM), as shown in Fig. 2 (c) (blue). This module fuses
features extracted by five-scale convolutional kernels using
a scale attention mechanism to generate attention weights
for fusion. By selectively extracting and fusing features at
targeted scales, it ensures adaptive capture of local details
and global contours for objects in diverse scenarios.
MFFM comprises two key components: multiscale fea-
ture extraction and adaptive fusion. For extraction, it em-
ploys a parallel multi-branch architecture with 1×1, 3×3,
5×5, 7×7, and 3×3 dilated convolutions. Small-scale con-
volutions (1×1, 3×3) capture fine local details, while larger-
scale and dilated convolutions extract broader contextual
information, enabling robust multiscale feature modeling
even with limited data. For fusion, an attention-based mech-
anism dynamically learns the importance weights for each
branch of the scale. The attention module assesses the dis-
criminability of the features and generates fusion weights,
adaptively fusing features based on their relevance. This
enhances scale-invariant detection and robustness in data-
scarce or complex scenarios. In the following, we detail the
implementation of MFFM in the model.

4. Experiment
We extensively evaluate PiDiViT for FSOD, OSOD, and
OVD tasks. Our evaluation includes comparisons with
SOTA methods, analysis under different sample sizes, and
qualitative comparisons with baseline models. Through ab-
lation studies, we examine each module’s contribution. The
results demonstrate that PiDiViT achieves a new SOTA per-
formance on the COCO dataset for all tasks, including 10-
shot/30-shot FSOD, OSOD, and OVD.
Evaluation Setup. We evaluate on COCO dataset [22]
following standard category splits [40, 45, 52]. The data set
is divided into base classes for training and novel classes for
testing. We measure novel class performance using nAP,
nAP50, and nAP75, and base class performance using bAP
and bAP50. For OSOD, following [27], we split 80 COCO
categories into 4 parts (Split-1/2/3/4), using 3 parts as base
classes and the remaining part as novel.
Implementation Details. PiDiViT builds on a two-stage
detection framework such as Mask R-CNN [13], using a pre-
trained RPN from [52] for proposal generation. The RPN is
trained only on base classes. We use frozen DINOv2 [29]
ViT-L as the backbone. Following Meta R-CNN [44], we
extract base class prototypes during training and add novel
class prototypes afterward without changing other parame-
ters. During the evaluation, we test base and novel classes,
extracting background prototypes from COCO Stuff [3]. In
inference, we select top-𝑇 categories (𝑇=10 for comparison
experiments, 𝑇=1 for ablations) based on feature distances
of prototype and proposal. Training losses include focal loss
and regression loss for category scores 𝑐𝑡 and boxes 𝑏𝑡 , BCE
loss, and Dice loss [38] for regions 𝑟𝑡 . For network stacking,
we stack three difference multiscale fusion layers.

5. Conclusion
We propose PiDiViT, a novel ViT architecture specifically
designed for few-shot object detection. In PiDiViT, we de-
sign explicit prior modules (DCFM and MFFM) for pixel-
level feature disparities and multiscale variability of pre-
trained ViT’s underlying features. DCFM achieves differ-
ential enhancement of smooth center-to-boundary features
while preserving global information, and MFFM enables
the capture of local details and global contours across multi-
ple scales. Experiments demonstrate that PiDiViT achieves
SOTA results on COCO FSOD, OSOD, and OVD tasks.
Despite these advancements, PiDiViT still has some lim-
itations. The inherent bias in the pretrained ViT may in-
fluence the projections of class-specific feature, particularly
when the class distribution is imbalanced. To address the
issue of ViT bias, we plan to design a fairness-constrained
algorithm for different classes in the future. This algorithm
will dynamically adjust the class weights during training to
mitigate the impact of pretrained ViT bias and further opti-
mize the performance balance between the novel and base
classes in scenarios with imbalanced class distributions.
