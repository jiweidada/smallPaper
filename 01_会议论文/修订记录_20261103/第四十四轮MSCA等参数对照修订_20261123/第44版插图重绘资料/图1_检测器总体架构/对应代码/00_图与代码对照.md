# 图 1　检测器整体架构

完整 n 模型的入口是 [deim.py](deim.py) 中的 `DEIM.forward`（第 26–31 行）。它依次调用 `self.backbone(x)`、`self.encoder(x)` 和 `self.decoder(x, targets)`。下表按一次推理中实际执行的顺序列出图里的模块。

| 图中模块 | 本目录中的代码 | 对应关系 |
|---|---|---|
| MPS 和四个主干阶段 | [hgnetv2_MSCA_EnhancedStem.py](hgnetv2_MSCA_EnhancedStem.py) 第 693–699、807–815、829–852、933–940 行 | B0 把输入传给 `EnhancedStemBlock`，随后依次执行四个 stage。`return_idx` 决定哪些阶段追加到 `outs`。 |
| 混合编码器 | [hybrid_encoder.py](hybrid_encoder.py)，`HybridEncoder.forward`，第 527–596 行 | 输入投影后，对配置选中的层执行 Transformer 编码，再做自顶向下和自底向上的多尺度融合。 |
| D-FINE 解码器 | [dfine_decoder.py](dfine_decoder.py)，`DFINETransformer.forward`，第 798–866 行 | 接收多尺度特征，构造解码器输入和查询。推理分支返回 `pred_logits` 和 `pred_boxes`。 |
| 检测框和类别分数 | [postprocessor.py](postprocessor.py)，`PostProcessor.forward`，第 53–103 行 | 将框转为原图坐标，根据类别分数选择预测，输出框、分数和标签。 |

## 两组输入端口从哪里来

| 配置来源 | 主干 `return_idx`（从 0 开始） | 编码器输入通道 | 步幅 | 编码器宽度 |
|---|---|---|---|---|
| [FULL_FRESH.yml](FULL_FRESH.yml)，主实验 n | [2, 3] | [512, 1024] | [16, 32] | 128 |
| [S1 模型配置摘录](S1_模型配置摘录.json)，历史 s | [1, 2, 3] | [256, 512, 1024] | [8, 16, 32] | 256 |

第 3 阶段的输出既被 n 编码器选中，也继续传到第 4 阶段。s 配置多选第 2 阶段。两组均以 640 × 640 作为评价输入尺寸。n 配置的 `DEIM`、`HybridEncoder`、`DFINETransformer` 和 `HGNetv2_MSCA_EnhancedStem` 分别始于第 223、233、255、324 行。

## 源码和配置来源

运行时，[fair_helpers.build](../../图6_FRESH验证曲线/对应代码/实验源码/fair_helpers.py) 读取配置的 `DEIM.backbone`，由[source_loader.register_selected_source](../../../../../远程公平对照_20261103/remote_evidence/source_loader.py) 第 168–171 行载入对应主干、检测器、编码器、解码器和后处理模块。

本目录五份 Python 文件保留原项目包的导入关系，逐文件与[本次运行冻结清单](../../../../../远程公平对照_20261103/公平主对照FRESH_20261112_v1/execution_protocol_30048.json)的 `source_snapshot/engine/` 条目核对。主干位于 `backbone/`，其余四份位于 `deim/`。

`FULL_FRESH.yml` 按[当时的配置生成代码](../../../../../远程公平对照_20261103/公平主对照FRESH_20261112_v1/driver/stage_arm.py)，使用[该次启动记录](../../../../../远程公平对照_20261103/公平主对照FRESH_20261112_v1/prepare_30048.json)中的数据路径和输出路径还原。文件 SHA-256 为 `562dd5b64e7f9e0dd523b02985e30332d8267bc24695dbb514fc01f5c81e9fff`，与 FULL_FRESH 全部 320 条指标记录的配置标识相同。

s 的 JSON 逐项提取自[S1 留存参数文件](../../../../source_snapshot/S1/args.json)的 `yaml_cfg`。原参数文件在[历史来源清单](../../../../source_manifest.json)中的 SHA-256 为 `00141951a69ce10fef5535b355ea8f4b8615da6a738051e40427e4bd0f12dfd4`。
