# 验证集公开归档与现存文件比对

## 核查结果

从 [HoangTrungNguyen 的第三方 VisDrone 镜像](https://huggingface.co/datasets/HoangTrungNguyen/VisDrone2019_training)下载了固定版本 `1171593dec3847a842ddc03e0e0b917b1a0fe45f` 的验证集 ZIP。归档为 81,638,851 字节，SHA256 为 `abeea063037e5d20398837deb11084e652402a34ddf4f207bdf541a6f2a35ef9`，与该版本 Git LFS 指针声明的大小和哈希一致。

在不解压到数据目录的情况下，分别读取归档内全部 548 个 JPEG 和 548 份原始 TXT 标注；两类文件均与现存文件和此前保存的相应清单逐文件相同。另用独立程序逐字节复核，仍为 **548/548 张图、548/548 份标注一致**。两张重复验证图以及各自不同的 TXT 标注也都存在于这个公开归档中。三次 CPU 重评回执绑定的验证图像清单和 COCO 标注哈希与本次核对范围一致。

该镜像说明页称其归档来自 Ultralytics 数据镜像。[Ultralytics 的 VisDrone 配置](https://github.com/ultralytics/yolov5/blob/master/data/VisDrone.yaml)确实列出同名验证集 ZIP；本轮读取的 GitHub 发布元数据中，同名文件大小也为 81,638,851 字节，但该发布元数据未给出 SHA256。因此，**大小相同不能证明两个 ZIP 字节相同**；本轮没有从 Ultralytics 另行下载文件比对。

对该第三方镜像的训练集 ZIP，使用 HTTP 范围请求读取目录及两对重复训练图对应的四份原始 TXT 标注；四份均与本地逐字节一致，并保存了小型标注快照。没有下载完整训练 ZIP 或读取其中的训练图片，也没有重算完整 ZIP 的声明哈希。另一个第三方镜像的四张训练 JPEG 指针此前与本地图像哈希一致；两个镜像并不因此成为官方认证。

## 官方来源的限制

[VisDrone 官方仓库](https://github.com/VisDrone/VisDrone-Dataset)列出的验证集 Google Drive 下载页面先显示大文件提示，确认后返回近期访问配额超限提示。没有获得官方归档，不能据第三方镜像推定官方原始图片或标注一定相同。前一轮将 HTML 响应原因记为未知；本轮读取页面可见提示后，现可将此次访问失败限定为该服务返回的配额提示，而不是推断本地文件错误。

与公开镜像的全量一致，增强了当前 548 条验证记录和原始标签的外部可追溯性；这仍不能认证历史训练时的数据字节，不能判定哪条标注正确，也不能量化重复与标注差异对 AP 的影响。此前六个重复 JPEG 与另一个公开镜像的 LFS 声明哈希也一致，但镜像可能共享上游来源，不能视为相互独立的官方认证。

## 后续比较的处理

现阶段没有充分依据删除重复记录或修改任何标签。若后续获授权执行公平 BASE/FULL 对照，可在重新核验并冻结同一数据哈希后，沿用现存 6,471/548 条记录及本地 COCO-style 评价协议；结果必须继续披露重复文件、标注差异和官方归档未认证的限制。若改用经核验的其他数据，应先重新固定数据清单、训练预算和评价端点，并取得相应实验授权。此核查没有启动任何训练、推理或评价。

## 证据

- `public_val_archive_audit.json`：固定仓库版本、ZIP 的 Git LFS 指针、归档哈希，以及全部文件与既存清单的 SHA256 比对。
- `independent_val_archive_verification.json`：全部 1,096 个对应文件的独立逐字节复核与三次 CPU 重评回执绑定。
- `official_val_http_diagnostic.json`：官方链接公开响应的页面提示；没有使用个人账号或上传本地数据。
- `ultralytics_release_metadata.json`：发布资产大小一致但未提供 SHA256；不能把它当作归档哈希证明。
- `public_mirror_VisDrone2019-DET-val.zip`：只读比对使用的第三方归档。未修改现有数据目录。
- `train_archive_range_probe.json`、`train_annotation_range_audit.json` 和 `independent_train_annotation_verification.json`：第三方训练 ZIP 的范围读取、四份标注的比较与独立复核；`public_train_annotation_snapshot` 保存四份只读比对副本。

公平 BASE/FULL 主对照尚未完成；目前仍不能宣布稿件达到投稿要求。
