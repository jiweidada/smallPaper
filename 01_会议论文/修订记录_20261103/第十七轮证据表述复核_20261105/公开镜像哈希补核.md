# 第三方公开镜像的图像指针补核

本轮只读取 [Voxel51 的 VisDrone2019-DET 第三方镜像](https://huggingface.co/datasets/Voxel51/VisDrone2019-DET)中六个重复文件和一个验证集参照文件的 Git LFS 小型文本指针，没有下载图像，也没有上传本地图片、标注或权重。将仓库版本固定为 `3c3b9e9bd44c91121c1fc19fce428f0e6b71bba2` 后重新读取指针，七个指针所声明的图像 SHA256 均与本地逐文件哈希一致。

六个问题文件在这个镜像中也形成与本地相同的三对图像哈希；例如验证集两个文件的指针分别见[第一条](https://huggingface.co/datasets/Voxel51/VisDrone2019-DET/raw/3c3b9e9bd44c91121c1fc19fce428f0e6b71bba2/data/0000022_00000_d_0000004.jpg)和[第二条](https://huggingface.co/datasets/Voxel51/VisDrone2019-DET/raw/3c3b9e9bd44c91121c1fc19fce428f0e6b71bba2/data/0000023_00000_d_0000008.jpg)。全部版本固定的 URL、指针原文、响应哈希和本地哈希见 `public_mirror_pinned_evidence.json`；第一次查询记录见 `public_mirror_pointer_audit.json`。

这表明相同的图像字节也出现在另一个公开副本中，因此不能直接把图像重复归因于本地复制或解压。该镜像不是 VisDrone 官方原始压缩包；LFS 指针是镜像提供的元数据，本轮未下载镜像图像、比较镜像标注或验证官方归档。不能据此断言官方原始数据一定包含这些重复，也不能确定标注差异的来源或 AP 影响。历史运行的数据身份仍未认证。

稿件第 4.1 节已经如实披露现存文件的事实和 CPU 重评范围，本次补核不改变稿件数值、图表或结论。公平训练对照仍需按既定要求事先取得明确授权。
